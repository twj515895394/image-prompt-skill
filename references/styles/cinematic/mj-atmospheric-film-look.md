# MJ 柔雾与梦境电影风格体系（写实 / 半写实 3DCG）

## 解决什么问题

把“MJ 风格垫图、柔光、低对比、低饱和、梦境感、电影感”等口语化意图拆解为可见的镜头、光照、材质、空间与色彩机制，同时避免将真实摄影与半写实 CGI 混为同一种媒介。

“MJ”仅为用户使用的审美简称：不是 Midjourney 官方风格分类、固定参数或生成效果保证。本页是 A–D 四种方向的**唯一风格正文真源**；通用灯光、电影剧照、皮肤和色板仍归各自既有叶子管理。

## 何时读取与反向边界

读取：用户明确要求 MJ 风格的柔雾电影底图、写实或半写实 CG 氛围帧；或同时出现“柔光低反差 + 写实/半写实 + 艺术电影/梦境”等能够决定媒介选择的线索。适用成片、图生图、场景氛围以及视频首帧、尾帧和关键参考帧。

不读取：只说普通“电影感”而需要叙事事件（优先 `film-still-language.md`）、只要求低饱和色调（现有色板库）、严格商品色产品广告、局部保真细节编辑、2D 动漫/像素/纯绘画媒介、纯硬光高饱和题材。角色板、服装板、分镜板即便命中此风格，其 Task 的版式与固定锚点仍优先。

## A–D 四种主方向

| 风格 | 明确信号 | 实际可见机制 | 常见题材 | 不能变成 |
|---|---|---|---|---|
| **A 写实奶油柔光** | 真实摄影、日常、亲密、温暖治愈、清晨、奶油色 | 窗光/天空漫射暖光，柔和阴影、奶油中间调、轻抬黑位，眼神和真实皮肤/针织纹理清楚 | 情侣 Vlog、家庭、亲子、温柔剧情、生活情绪 | 塑料磨皮、白雾盖脸、无明暗体积 |
| **B 写实灰雾电影** | 真实摄影、阴天、雨后、冷灰、克制、孤独、疏离 | 低饱和冷中性灰、可信环境光，远景薄雾、湿地反射与主体局部明度分离 | 都市街头、文艺叙事、清冷古风、雨中人物 | 欠曝死黑、全图均匀灰、没有焦点 |
| **C 梦境艺术电影** | 诗意、记忆、梦核、超现实但具现实质地、幻想空间、云海花海 | 被设计过的空间秩序、负空间与尺度反差、轻体积光、柔和统一色群，物体仍有重量和接触关系 | AI MV、意识流、唯美奇幻、概念片 | 随机拼贴、过量雾、必然二次元/水彩 |
| **D 半写实 3DCG 电影** | 明确 CG、3DCG、semi-realistic、动画电影静帧、理想化建模 | 可信三维体积，皮肤/布料/发丝/场景材质的相容反射，柔和体积光，精致但有结构的造型 | 3D 人物 IP 短片、CG 艺术镜头、幻想角色电影帧 | 玩具塑料皮、过锐游戏截图、真人脸贴模型 |

**维度并非完全互斥。** A/B 更偏真实摄影，C 主要决定梦境化艺术指导，D 主要决定 CG 媒介。**必须选择一个主方向**，允许次级氛围跨类借用（例如“暖奶油色 3DCG”以 D 为主、A 的暖光作辅助；“写实梦境森林”以 C 为主并保留真实材质），但不可在同一画面同时要求“完全真实纪实摄影”和“明显塑料建模皮肤”。

## 自动定位算法

按证据强度逐层判断，前者覆盖后者：

1. **明确指定**：用户明确媒介、风格编号、必须保留的身份/构图/材质和参考图职责，不得被风格推断重写。
2. **参考图**：辨别光线、真实镜头感、材质和空间是否呈摄影/CG 特征；只从指定为风格来源的参考图提取风格，不把服装参考图当全局风格依据。
3. **媒介优先**：明确 3DCG/半写实渲染选 D，即使暖色或冷色；明确真实摄影则在 A/B/C 中结合叙事判断。
4. **氛围优先**：真实日常暖柔选 A；真实阴天冷灰克制选 B；诗意超现实空间/梦境主导时选 C。
5. **有限混合**：两个方向并存时，选择最能决定主体媒介和第一视觉机制的方向为主，其他仅进入光色与情绪修饰；不一次给四个完全不同的 Prompt。
6. **证据不足**：结合上下文和任务作最小风险推断；“只有 MJ 柔光、无明显 CG/梦境证据”的现实题材默认 A，雨夜孤独默认 B，奇幻梦境默认 C，只有 CG 证据才默认 D。
7. **不可裁决的大分歧**：仅当用户允许先确认或明确要求比较方向、且“真实摄影 vs 半写实 CGI”等分歧会实质影响成片时，转入原有交互模式，给一次 A–D 风格选择。普通快速模式继续自动定稿、不追问；用户明确“直接出图”时绝不插入风格问卷。

### 交互模式的单问题选项

> 你希望画面主要偏向哪种质感？A 写实奶油柔光（暖调自然摄影）／B 写实灰雾电影（冷灰克制摄影）／C 梦境艺术电影（诗意轻超现实）／D 半写实 3DCG（精致三维电影静帧）。根据当前题材，我推荐 **[由实际输入推断的单一风格]**；也可以说“按推荐”。

已由文字/参考图确定的内容不问。不要为了色温、颗粒多少或镜头小细节追问。只有一个问题，不连环选择。

## 共同的视觉规则

1. 先写主体身份/材质、场景、动作瞬间、观看距离和第一视觉落点，风格为其服务；不用“高级感、MJ 感”替代画面。
2. 柔光必须有光源动机：清晨薄纱窗、阴天穹顶、环境反射、设定合理的体积光。软阴影依然显示鼻梁、下颌、衣褶、接触与景物结构。
3. 低对比并非全图发灰：柔化高光滚降、轻抬黑位但保留必要暗部深度；主体和背景有明度、冷暖或清晰度的局部分离。
4. 低饱和并非抽去全部颜色：保留自然肤色、角色标识色和道具识别色；暖灰/冷灰色群要与实际光源一致。
5. 薄雾与高光 bloom 局限于空气纵深和局部亮源，眼神、五官边缘、发丝、布料和主道具保持清晰；胶片颗粒可选，不得覆盖细节。
6. A/B 的真实镜头、皮肤纹理和空间透视遵循摄影逻辑；C 的空间可以有轻微诗意失真，但质地与物理联系仍一致；D 的几何体积、反射/粗糙度和接触阴影必须统一，避免蜡像 CG。
7. 一个主焦点通过面积、明度、清晰度和构图共同形成；留白与雾气不得吞掉主体。

## 四种方向的完整场景示例

**A 写实奶油柔光。** 清晨卧室，一位穿浅米色针织衫的女性坐在窗边端着陶瓷杯，平视中近景从侧前方观察；薄纱窗帘将自然晨光扩散为暖白的侧面主光，皮肤真实细腻但保留眼睫、发丝和脸颊细微起伏，奶油白与暖灰中间调让床品融入安静环境，阴影略抬但杯柄和衣褶仍有体积，背景轻微虚化，亮窗周围仅有细微柔晕。

**B 写实灰雾电影。** 雨后老城区街角，一位穿深灰大衣的年轻人刚停下脚步回头，平视中景透过前景玻璃观察；阴天自然散射光投向冷灰墙面，街道远处被薄雾拉开距离，湿路面留下微弱反射，蓝灰石板色调低饱和但保留自然肤色，脸部比背景略亮，衣料与雨滴清楚，不是全局模糊或暗部死黑。

**C 梦境艺术电影。** 一名旅人站在巨大石拱门前，身下石阶仍有真实磨损与重量，远处重复的拱门逐层消失在柔和云雾；中远景低机位以诗意对称和负空间建立人物与空间的尺度，天空扩散光照亮淡灰粉和褪色青绿，少量体积光强调拱门深度；世界带超现实秩序却保留接触、透视、材质与视觉中心。

**D 半写实 3DCG 电影。** 一名五官精致但保留自然骨骼关系的少年站在松林薄雾中，身穿深蓝织物外套，镜头在胸口高度中近景观察；三维电影静帧，柔和的天空主光映在发丝、皮肤与衣物褶皱上，不同材质有一致而可信的粗糙度和高光响应，背景青灰而肤色略暖，角色接触阴影稳定，脸部有生命感而不是玩具塑料或过度锐化的游戏建模。

这些是机制示例，不是固定场景模板。对实际用户请求必须生成包含其主体、场景、镜头、动作、材质和限制的完整 Prompt，并经 Prompt Finalization，不直接拷贝上面示例替代用户目标。

## 图生视频静态垫图专用

- 静态首帧先建立动作起点、身体/道具接触、运动方向的画面留白；让手指、眼睛、衣摆、头发和主要道具可辨，避免提前涂糊。
- 同一段影片的多张底图固定身份、服装、场景地标、主光方向、媒介、主色群、主要材料；需要改变镜头或动作时按视频参考帧 Playbook 显式处理可变项。
- 控制高频背景杂物及不必要的光源竞争，但不牺牲必要叙事证据与角色细节。
- 柔光低反差并不能保证 H3 或其他图生视频模型没有闪烁、伪影与续接错误；本页只负责静态风格一致性，不输出逐秒运镜或视频采样参数。

## 常见失败与 QC 修复

- **过雾过糊**：近处眼神、衣料和道具不清 → 只保留远景 haze 和局部 bloom，恢复焦点细节。
- **低对比变平**：主角与环境融为同灰 → 恢复主体局部明度/色温差、前中后景层次。
- **CG 媒介泄露**：A/B 人像像塑料娃娃，D 又拼贴真实面孔 → 统一材质、形体、光线与目标媒介。
- **梦境无物理规则**：C 场景的物体漂浮、接触冲突或透视不连贯 → 仅保留一项诗意超现实机制，其余遵守统一场景逻辑。
- **过度褪色**：肤色与衣服标识色丢失 → 恢复主体保留色。
- **跨帧跳风格**：核对 A–D 主方向、光源、色群、皮肤/CG 质地、场景结构是否稳定。
- **侵犯参考锚点**：重新分配身份/服装/场景/风格来源，确保原 Task 和用户显式锁定项优先。

最终自查：去掉“MJ、dreamy、cinematic”标签后，是否仍能由具体镜头位置、可信光源、对比关系、材质反应、空间与情绪读出画面？是否只有一个主媒介和主方向？人物身份、版式、参考图职责是否守住？不通过则自动修复并经统一 Prompt Finalization / QC / 复检后输出。
