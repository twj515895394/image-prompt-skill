# MJ 风格与光学呈现体系（写实 / 半写实 3DCG）

## 解决什么问题

把“MJ 风格垫图、柔光、低对比、低饱和、梦境感、电影感”等口语化意图拆解为可见的镜头、光照、材质、空间与色彩机制，同时避免将真实摄影与半写实 CGI 混为同一种媒介。

“MJ”仅为用户使用的审美简称：不是 Midjourney 官方风格分类、固定参数或生成效果保证。本页是 A–D 四种方向的**唯一风格正文真源**；通用灯光、电影剧照、皮肤和色板仍归各自既有叶子管理。

## 何时读取与反向边界

读取：MJ 风格是本次生图或图生图的目标时，包括用户只说“MJ 风格”的情况；也适用于写实或半写实 CG 氛围帧，以及同时出现“柔光低反差 + 写实/半写实 + 艺术电影/梦境”等能够决定媒介选择的线索。此时默认把光学呈现和散景作为可调整的风格层，适用于成片、图生图、场景氛围以及视频首帧、尾帧和关键参考帧。

不读取：只说普通“电影感”而需要叙事事件（优先 `film-still-language.md`）、只要求低饱和色调（现有色板库）、严格商品色产品广告、局部保真细节编辑、2D 动漫/像素/纯绘画媒介、纯硬光高饱和题材。角色板、服装板、分镜板即便命中此风格，其 Task 的版式与固定锚点仍优先。

## A–D 四种主方向

| 风格 | 明确信号 | 实际可见机制 | 常见题材 | 不能变成 |
|---|---|---|---|---|
| **A 写实奶油柔光** | 真实摄影、日常、亲密、温暖治愈、清晨、奶油色 | 窗光/天空漫射暖光，柔和阴影、奶油中间调、轻抬黑位，眼神和真实皮肤/针织纹理清楚 | 情侣 Vlog、家庭、亲子、温柔剧情、生活情绪 | 塑料磨皮、白雾盖脸、无明暗体积 |
| **B 写实灰雾电影** | 真实摄影、阴天、雨后、冷灰、克制、孤独、疏离 | 低饱和冷中性灰、可信环境光，远景薄雾、湿地反射与主体局部明度分离 | 都市街头、文艺叙事、清冷古风、雨中人物 | 欠曝死黑、全图均匀灰、没有焦点 |
| **C 梦境艺术电影** | 诗意、记忆、梦核、超现实但具现实质地、幻想空间、云海花海 | 被设计过的空间秩序、负空间与尺度反差、轻体积光、柔和统一色群，物体仍有重量和接触关系 | AI MV、意识流、唯美奇幻、概念片 | 随机拼贴、过量雾、必然二次元/水彩 |
| **D 半写实 3DCG 电影** | 明确 CG、3DCG、semi-realistic、动画电影静帧、理想化建模 | 可信三维体积；人物可有理想化五官，但保留接近真人的骨骼关系和身体比例；皮肤有柔和色层与轻微透光，发丝、织物和场景材质有相容的粗糙度与高光响应 | 3D 人物 IP 短片、CG 艺术镜头、幻想角色电影帧 | 玩具塑料皮、蜡像般无层次、平面动漫、过锐游戏截图、真人脸贴模型 |

**维度并非完全互斥。** A/B 更偏真实摄影，C 主要决定梦境化艺术指导，D 主要决定 CG 媒介。**必须选择一个主方向**，允许次级氛围跨类借用（例如“暖奶油色 3DCG”以 D 为主、A 的暖光作辅助；“写实梦境森林”以 C 为主并保留真实材质），但不可在同一画面同时要求“完全真实纪实摄影”和“明显塑料建模皮肤”。

## 自动定位算法

### 仅说“MJ 风格”时：弱信号与主体驱动

**MJ 对主媒介、整体色调和梦境氛围仍是弱信号，但当它是目标风格时，会默认开放光学呈现层。** 用户只说“MJ 风格”且没有其他 A–D 视觉线索时，仍依据题材与用途判断主媒介和整体色彩；不强制选择 A–D 中的某个方向，也不强制低饱和、灰雾、梦境或 CGI。但应主动考虑适合该画面的光学变化，例如略浅的景深、轻度面部光学柔化、局部高光晕染和克制的前后景散景。普通高保留或只转媒介/材质的要求，不得被自动解读为必须保留原景深或散景。光学层是可调整范围，不意味着所有效果都必须叠加；保持焦点与主体结构，避免厚白雾、整幅失焦或挡住五官的光斑。明确要求原景深、光学效果或光斑不变时，遵循该项具体限制。

### 仅凭弱信号的选择步骤

1. 识别**主体领域**（真人日常、现实街景、神话生物、幻想建筑、产品/工业对象、3D 角色等）、图像任务（成片、概念图、资产板、首帧等）、用户最重视的质量轴（复杂细节、材质、史诗尺度、情绪、设计精度）。
2. 先补**主体辨识结构与细节逻辑**，再选择媒介、镜头、光色与场景。神话生物重形态、骨骼和附属结构；建筑重空间与尺度；角色重身份和服装；产品重准确形态与材质，而不是一律添加模糊柔雾。
3. 在没有明确媒介时按题材倾向而非硬编码分类：温馨真实日常通常偏 **A**；冷灰现实情绪通常偏 **B**；东方神话生物、奇幻世界、梦境概念通常偏 **C** 或非柔雾的高完成度奇幻概念方向；明确三维制作/3DCG 偏 **D**。这些只是弱默认，不得用“东方”“龙”“狐狸”“未来城市”等一个词直接断定效果。
4. 把“复杂细节精致”写成可观察的**形体层次、材质响应、轮廓、接触、结构密度、局部微细节**；细节服从景别，不通过无差别叠加辉光、薄雾、锐化或大量词语制造所谓精致。
5. 若无充分依据决定柔雾低反差是否适合，**不强加**；按主体需求决定适当对比（如白龙的珠白鳞片与背景应能分离）、高光、清晰度、色彩与空间层次。
6. 若差异会实质影响最终媒介，并且用户明确允许先确认，最多问一次建议选项（必要时将 A/C/D 改述为“写实神话生物摄影 / 梦境艺术电影 / 半写实 3DCG”），给一个推荐项；快速模式继续自动推断并直接输出。

### 例子：MJ 风格的复杂精致东方白龙

**主要意图**：东方神话白龙 + 复杂精美结构 + 高完成度奇幻画面。优先选择具有诗意神话空间与电影表现的 **C 梦境艺术电影**作为 *可行默认方向*，但梦境与低对比仅作为适度表现；如果用户要写实自然纪录片般的生物则改写实媒介，如果用户明确要 3DCG 则选择 D。不能因“白龙”默认西方有翼四足龙或塑料动画玩具。

- **主体结构**：修长游动的蛇形龙身，符合东方龙视觉传统的角、须、鬃、鳞、四肢与爪的连续关系；完整长身或必要的重点局部由镜头景别决定。
- **精致证据**：珠白/银白鳞片有重叠方向、大小节奏与微弱高光差异；龙角分叉有层次，长须和鬃毛随姿态形成细线条，爪与背脊结构可读；精细不等于把每片鳞片写成完全相同的白点。
- **空间/照明**：可选择有规模参照的远山云海与散射天光，适度体积光描边，但龙首、眼神、主躯干必须优先清楚；白龙轮廓与淡色云海应以色温/明度差分离。
- **QC**：无西方蝠翼误加、龙身断裂、肢体数量混乱、鳞片糊成一片、头须与背景粘连、全图泛白无焦点，以及过量梦幻特效吞没结构。

可用于最终 Prompt 的语义示例（需要依据用户实际画幅、参考图和任务继续具体化并最终化）：一条优雅而威严的东方白龙盘旋于高山云海之上，蛇形长躯以连贯曲线穿过云层，分叉龙角、流动长须、鬃毛、四肢与龙爪具有完整可信的结构关系；细密珠白鳞片沿身体方向重叠排列，反射出微弱银光和冷青边缘色。观众从略低机位的中远景看见龙首与主要躯干，天光从云层间照亮龙首和脊背，远山提供尺度参照，少量薄雾建立纵深而不遮蔽鳞片，白龙与背景有明确的局部明暗和色温分离，整体呈高完成度东方神话奇幻电影画面。

### 反例与不强制路由

- “MJ 风格的工业零件，尺寸结构要准”：产品/工业控制优先；不要擅加 C 梦境、柔雾或神话装饰。
- “MJ 风格的未来城市”：可能是写实建筑摄影、史诗奇幻或 CG 世界观，按描述与参考图判断，不自动归 C。
- “MJ 风格的古风少女”：身份、时代服饰、题材与摄影/CG 线索优先，不见“古风”就默认 C；只有强梦境/幻想机制才选 C。
- “MJ 风格的白龙，纯硬光高对比、红金色、游戏概念图”：显式硬光和色彩要求优先，不强制使用柔雾低饱和。



按证据强度逐层判断，前者覆盖后者：

1. **明确指定**：用户明确媒介、风格编号、必须保留的身份/构图/材质和参考图职责，不得被风格推断重写。
2. **参考图**：辨别光线、真实镜头感、材质和空间是否呈摄影/CG 特征；只从指定为风格来源的参考图提取风格，不把服装参考图当全局风格依据。
3. **媒介优先**：明确 3DCG/半写实渲染选 D，即使暖色或冷色；明确真实摄影则在 A/B/C 中结合叙事判断。
4. **氛围优先**：真实日常暖柔选 A；真实阴天冷灰克制选 B；诗意超现实空间/梦境主导时选 C。
5. **有限混合**：两个方向并存时，选择最能决定主体媒介和第一视觉机制的方向为主，其他仅进入光色与情绪修饰；不一次给四个完全不同的 Prompt。
6. **证据不足**：结合上下文和任务作最小风险推断；“只有 MJ 柔光、无明显 CG/梦境证据”的现实题材默认 A，雨夜孤独默认 B，奇幻梦境默认 C，只有 CG 证据才默认 D。
7. **不可裁决的大分歧**：仅当用户允许先确认或明确要求比较方向、且“真实摄影 vs 半写实 CGI”等分歧会实质影响成片时，转入原有交互模式，给一次 A–D 风格选择。普通快速模式继续自动定稿、不追问；用户明确“直接出图”时绝不插入风格问卷。

### 交互模式的单问题选项

> 你希望画面主要偏向哪种质感？A 写实奶油柔光（暖调自然摄影）／B 写实灰雾电影（冷灰克制摄影）／C 梦境艺术电影（诗意轻超现实）／D 半写实 3DCG（精致三维电影静帧）。根据当前题材，我推荐 **[由实际输入推断的单一风格]**；也可以说“按推荐”。

已由文字/参考图确定的内容不问。不要为了色温、颗粒多少或镜头小细节追问。只有一个问题，不连环选择。

## 共同的视觉规则

1. 先写主体身份/材质、场景、动作瞬间、观看距离和第一视觉落点，风格为其服务；不用“高级感、MJ 感”替代画面。
2. 柔光必须有光源动机：清晨薄纱窗、阴天穹顶、环境反射、设定合理的体积光。软阴影依然显示鼻梁、下颌、衣褶、接触与景物结构。
3. 低对比并非全图发灰：柔化高光滚降、轻抬黑位但保留必要暗部深度；主体和背景有明度、冷暖或清晰度的局部分离。
4. 低饱和并非抽去全部颜色：保留自然肤色、角色标识色和道具识别色；暖灰/冷灰色群要与实际光源一致。
5. **景深和光学柔化分开写。** 浅景深只决定焦平面前后的虚化，先说明焦点落在哪里；人物人像通常让眼睛或面部仍处在焦平面。MJ 作为目标风格时，可默认适度调整景深以塑造前后层次；景深浅不等于主体失焦。
6. **光学柔化是另一层效果。** MJ 作为目标风格时，默认考虑轻薄光学扩散、面部边缘的微柔化和局部高光晕染；人物可以显得柔和，但五官关系、表情和主体结构仍须可辨。它不等于整张图失焦，也不等于铺一层厚白雾。场景雾只负责空气纵深，bloom 贴合局部亮源。
7. **默认设计克制的焦外光斑。** 可利用背景已有亮源，也可加入少量与场景相容的前景或背景散景，安排其大小、亮度和冷暖，使其衬托主焦点；不得遮住眼睛或主要五官，也不要无依据增加多色霓虹或强烈新光源。
8. A/B 的真实镜头、皮肤纹理和空间透视遵循摄影逻辑；C 的空间可以有轻微诗意失真，但质地与物理联系仍一致；D 的几何体积、反射/粗糙度和接触阴影必须统一。半写实人物皮肤保留细腻层次与适度材质感即可，不强求毛孔级超写实，也不抹成绝对光滑的蜡面。
9. 一个主焦点通过面积、明度、清晰度和构图共同形成；留白与雾气不得吞掉主体。

### D 向半写实 3DCG 人像的执行顺序

仅在目标明确为半写实 3DCG 人物或人像时使用。依次安排主体与外形、半写实程度、皮肤/头发/衣物材质、姿态与景别、光源方向与补光、浅景深和焦外光斑、适度的光学柔化与高光晕染、配色，最后只保留必要排除项；若 MJ 是目标风格，默认评估并安排适合画面的光学变化，不强制每种效果全部出现。

五官可以精致理想化，但保持接近真人的骨骼关系和身体比例。肤质可写细腻的色层、柔和明暗过渡和轻微透光；不反复追加毛孔级超写实，也不要求完全无纹理。若要比较迭代效果，固定材质、灯光、柔化和配色层，每轮只调整一两项主体变量；这属于试验方法，不必写进单次最终 Prompt。

## 四种方向的完整场景示例

**A 写实奶油柔光。** 清晨卧室，一位穿浅米色针织衫的女性坐在窗边端着陶瓷杯，平视中近景从侧前方观察；薄纱窗帘将自然晨光扩散为暖白的侧面主光，皮肤真实细腻但保留眼睫、发丝和脸颊细微起伏，奶油白与暖灰中间调让床品融入安静环境，阴影略抬但杯柄和衣褶仍有体积，背景轻微虚化，亮窗周围仅有细微柔晕。

**B 写实灰雾电影。** 雨后老城区街角，一位穿深灰大衣的年轻人刚停下脚步回头，平视中景透过前景玻璃观察；阴天自然散射光投向冷灰墙面，街道远处被薄雾拉开距离，湿路面留下微弱反射，蓝灰石板色调低饱和但保留自然肤色，脸部比背景略亮，衣料与雨滴清楚，不是全局模糊或暗部死黑。

**C 梦境艺术电影。** 一名旅人站在巨大石拱门前，身下石阶仍有真实磨损与重量，远处重复的拱门逐层消失在柔和云雾；中远景低机位以诗意对称和负空间建立人物与空间的尺度，天空扩散光照亮淡灰粉和褪色青绿，少量体积光强调拱门深度；世界带超现实秩序却保留接触、透视、材质与视觉中心。

**D 半写实 3DCG 人像。** 一位偏日系审美的年轻女性以中近景入画，日系电影级半写实三维角色，五官精致理想化但面部骨骼、表情和人体比例接近真人；白皙肤色有细腻层次、柔和明暗过渡和轻微透光感，不强调毛孔，也不磨成蜡面，发丝与衣料保留可信的材质响应。侧后方柔光勾出发丝和肩部轮廓，正面弱柔光托住面部；浅景深虚化前后景，焦点仍落在眼睛与面部。轻薄黑柔滤镜般的光学扩散也柔化面部边缘、降低局部对比，高光自然晕染；蓝灰环境衬出温暖肤色，暖黄与冷白散景分布在背景和少量前景但避开眼睛。画面保留五官结构与主体轮廓，不出现塑料皮肤、蜡像、平面动漫、过度锐化、厚重白雾或整体失焦。

这些是机制示例，不是固定场景模板。对实际用户请求必须生成包含其主体、场景、镜头、动作、材质和限制的完整 Prompt，并经 Prompt Finalization，不直接拷贝上面示例替代用户目标。

## 图生视频静态垫图专用

- 静态首帧先建立动作起点、身体/道具接触、运动方向的画面留白；让手指、眼睛、衣摆、头发和主要道具可辨，避免提前涂糊。
- 同一段影片的多张底图固定身份、服装、场景地标、主光方向、媒介、主色群、主要材料；需要改变镜头或动作时按视频参考帧 Playbook 显式处理可变项。
- 控制高频背景杂物及不必要的光源竞争，但不牺牲必要叙事证据与角色细节。
- 柔光低反差并不能保证 H3 或其他图生视频模型没有闪烁、伪影与续接错误；本页只负责静态风格一致性，不输出逐秒运镜或视频采样参数。

## 常见失败与 QC 修复

- **柔化变成失焦或白雾**：先判断问题来自景深、光学扩散还是空气雾；保留焦平面上的五官结构，减弱厚重雾层和脱离亮源的 bloom。若目标明确要求柔化面部，可保留轻微软化而不抹掉表情与轮廓。
- **软光与锐度指令打架**：同时要求黑柔扩散、全画面极锐、超高微细节或强 HDR → 删除彼此冲突的强调词，只保留焦点区域所需的结构与材质细节。
- **散景遮住五官**：将前景光斑移离眼睛和主体识别区，压低其面积与亮度。
- **低对比变平**：主角与环境融为同灰 → 恢复主体局部明度/色温差、前中后景层次。
- **CG 媒介泄露**：A/B 人像像塑料娃娃，D 又拼贴真实面孔 → 统一材质、形体、光线与目标媒介。
- **梦境无物理规则**：C 场景的物体漂浮、接触冲突或透视不连贯 → 仅保留一项诗意超现实机制，其余遵守统一场景逻辑。
- **过度褪色**：肤色与衣服标识色丢失 → 恢复主体保留色。
- **跨帧跳风格**：核对 A–D 主方向、光源、色群、皮肤/CG 质地、场景结构是否稳定。
- **侵犯参考锚点**：重新分配身份/服装/场景/风格来源，确保原 Task 和用户显式锁定项优先。

最终自查：去掉“MJ、dreamy、cinematic”标签后，是否仍能由具体镜头位置、可信光源、对比关系、材质反应、空间与情绪读出画面？是否只有一个主媒介和主方向？人物身份、版式、参考图职责是否守住？不通过则自动修复并经统一 Prompt Finalization / QC / 复检后输出。
