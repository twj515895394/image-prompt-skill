# 静帧 VFX 家族参考库

## 解决什么问题

为单张生图、图生图或静态参考帧提供可选的特效家族、轮廓和载体线索。它提供“有哪些视觉构成”，不代替 VFX 构造控制中的选择、取舍与画面整合方法。

## 什么时候读取

当画面需要具象的场内特效，并需要从能量、元素、法术、冲击、召唤等形式中确定视觉形态时读取。只有景深、散景、镜头眩光、高光晕染或光学柔化时不读取。

## 特效家族

| 家族 | 可辨认的视觉签名 | 适合表达 | 常见失误 |
|---|---|---|---|
| 能量场与灵光 | 能量核心、场域边缘、束流、弧线、流动丝带或局部形变 | 聚能、护盾、持续增幅、力量状态 | 只有泛光，读不出核心、范围或来源 |
| 元素与自然力量 | 火舌与热扰动；水幕、波纹与飞溅；冰晶与霜线；风压弧带与被吹动物；岩石裂层与尘屑；沿导电路径分叉的电弧 | 火、水、冰、风、土石、雷电等自然或超自然力量 | 只换元素配色，形态仍相同；效果不回应介质和受力 |
| 弹体与光束 | 清楚的发射点、连续束体或单个弹体、方向与宽度变化、命中位置或终点 | 射击、投掷、能量束、远距离作用 | 发射源不明、路径无方向、终点被裁切或出现无依据的多发副本 |
| 武器轨迹与运动残影 | 贴合刀刃、枪口、拳脚或移动物体的弧线、窄带、切面、短暂残影或真空边缘 | 斩击、挥击、快速移动、近身冲击 | 轨迹脱离武器路径，或残影改变武器的数量、握持和身份 |
| 命中与冲击波 | 接触核心、环形或弧形压力前沿、向外扩散的碎片、扬尘、水波或材质裂纹 | 重击、爆发、着陆、冲撞、范围作用 | 只有无来源的光环，目标与受力方向没有变化 |
| 法术、符印与结界 | 有秩序的线条、符记、材质载体、封闭或开放边界、明确的操作面 | 封印、护持、仪式、召唤条件、空间规则 | 装饰符号堆叠，无法看出边界、对象或作用方式 |
| 召唤与空间异象 | 门槛、裂口、折叠平面、透视变化、局部显现、前后遮挡与环境接触 | 召唤、传送、异空间、尺度揭示 | 传送口像贴图，显现物没有与空间或地面发生关系 |
| 转化与有机生长 | 可追踪的变化前沿、逐步替换的表面、纤维、膜、晶化、蔓延或愈合边缘 | 变身、腐蚀、感染、修复、物质变化 | 全身同时糊变，身体结构或身份特征崩坏 |
| 破坏与碎片 | 从实际受力处延伸的裂纹、依材质而异的碎块、飞散方向、落点或残骸 | 崩裂、爆破、撞击后果、结构瓦解 | 所有材料都碎成同一种灰尘，碎片没有来源与动量 |
| 环境与气氛场 | 有深度层次的烟、灰、雨、雪、尘、雾或落叶，带可读的来源、风向、密度和受光差异 | 天气、余波、战场环境、危险氛围、空间传播介质 | 厚雾吞掉主体；真实环境介质与镜头柔雾混为一层 |

## 可组合的视觉维度

粒子通常是载体或陪衬，不必单独变成特效家族。可按主效果需要描述发射位置、形状大小、疏密分布、运动方向、景深位置、亮度层级和与物体接触后的状态。粒子数量不等于特效强度。

可选载体包括发光丝流、弧线、薄片、晶屑、液滴、火星、灰烬、烟尘、纸片、符线、碎片和局部折射。颜色服务于来源、材质和主次识别；不把特定色彩当作元素的唯一识别方式，也不强制套用固定元素色板。

## 风格与媒介边界

- 同一画面中的特效应继承主体的主要渲染媒介、边缘语言、细节密度和颜色层级。
- 半写实或写实 CG 可根据载体选择体积、透明、反射、折射、热扰动和局部光照；不要求所有效果都使用发光体。
- 纯动画、像素或平面插画可以采用各自的形状与线条语言，但不自动替换用户指定的 CG 媒介。
- 镜头散景、高光柔化、光学晕染和镜头眩光属于风格层，不是本库中的场内法术、火花或粒子。
