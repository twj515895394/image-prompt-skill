# Material & Effect Library

当任务需要具体材质、表面状态、反射、透明、湿润、磨损、烟雾、火焰、粒子或其他视觉效果资料时读取本分类。

本目录保存可选材质和效果资料；材质如何与光线、风格和真实感协调仍由 controls 与 styles 负责。

## 场内视觉特效

当画面需要火焰、能量、法术、冲击、武器轨迹、召唤、转化或破坏等场内 VFX，并需要比较具体效果家族时，读取：

- [vfx-effect-families.md](vfx-effect-families.md)

如何为单张图选择主效果、冻结关键状态并组织其来源与场景响应，读取 [VFX 构造控制](../../controls/effects/vfx-construction.md)。镜头景深、散景、柔化和高光晕染仍由对应 styles 或 controls 负责。
