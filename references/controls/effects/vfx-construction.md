# 静帧 VFX 构造控制

## 解决什么问题

把能量、元素、法术、冲击、召唤、变化和破坏等场内视觉特效，从效果名词转成一张图中可辨认、能说明作用、并与主体和环境发生联系的画面。此页负责选择和组织特效机制，不负责完整视频时序、游戏引擎粒子参数或着色器实现。

## 什么时候读取

- 用户要生成或改写一张带有明确场内 VFX 的画面，例如施法、能量束、元素攻击、武器轨迹、冲击波、传送或变形。
- 特效需要与人物、道具、目标物或场景发生接触、照明、遮挡或材质变化。
- 单张视频参考帧需要呈现清楚的特效起点、状态或结果。

只要求浅景深、散景、镜头柔化、高光晕染或镜头眩光时不读取；这些属于镜头光学呈现，走对应风格或光线规则。MJ 目标风格默认开放光学层，但不会因此自动增加法术、火花或其他场内特效。单纯出现 CG、奇幻或电影感字样，也不足以凭空添加一种能力或攻击。

## 核心构造

### 1. 确定特效在画面中的职责

先判断特效要让观众读懂什么：力量来源、移动路径、命中方向、范围尺度、状态改变、空间边界或环境状态。确认特效是主视觉还是支撑信息，并让亮度、面积、对比和细节密度服务于该层级。

### 2. 选择一种主家族

根据效果实际作用读取同目录的 VFX 家族参考库。优先选一个主家族；只有第二种效果确实解释不同的画面信息时才增加一个辅家族。不要把法阵、闪电、火焰、烟雾和粒子当作默认套装，也不要只靠换颜色区别效果。

### 3. 为单张图冻结一个可读瞬间

静帧只呈现一个决定性状态：效果正在形成、沿路径推进、发生接触、到达峰值，或留下清晰残留。不要在一张图里按时间顺序写完整的蓄力、发射、命中、消散流程。可保留辨认此瞬间所需的源头、路径或结果线索。

### 4. 建立可见的因果关系

按画面需要组织以下信息，不必机械填满每一项：

效果职责 → 来源或发射点 → 当前状态 → 载体材质与主轮廓 → 画面位置和空间层 → 路径或作用对象 → 主体与环境响应 → 局部光照和遮挡 → 残留或稳定结果

至少让观众看清效果从哪里来、长什么样，以及它正在作用于什么或如何改变场景。没有单一发射者的雾场、天气或能量场，应明确其场域边界、传播介质或环境来源。

### 5. 让特效服从全画面的渲染媒介

- CG 特效与人物、道具和环境保持一致的体积、材质粗糙度、边缘处理、景深和遮挡关系；若明确要求半写实 3DCG，不把特效画成无空间层次的平面贴纸。
- 发光效果按其位置与强度影响附近物体，可在相邻表面形成局部染色、反射或亮边；只写画面能支持的光照证据，不用整幅泛白光雾代替局部响应。
- 神秘或超自然效果可以偏离日常物理，但需维持一套稳定的形态和作用规则，并与接触对象及空间层次相容。
- 使用 MJ 风格时由 MJ 风格叶子决定主媒介与镜头光学呈现；本控制只组织场内效果，不额外改写人物、构图、色调或镜头风格。

### 6. 合并进当前 Prompt

把效果来源、形态、路径或当前作用、局部响应写进当前任务的完整画面描述。快速模式仍只交付最终 Prompt，不输出内部特效卡、拆解字段、方向说明或质量检查过程。图生图和局部编辑遵循任务 Playbook 的保留边界；只有用户授权的区域或元素可随特效变化。

## 常见失败与修复

| 失败表现 | 修复方向 |
|---|---|
| 特效像漂浮装饰，没有作用来源 | 绑定到人物、武器、装置、接触点或明确的环境源；纯氛围场则交代场域来源 |
| 只有光团或“很强的能量” | 给出可辨认的主轮廓、载体、空间位置和一种运动或作用特征 |
| 一张图里同时出现多种不相关效果 | 保留最能说明画面目标的主家族，删去只增加噪声的装饰效果 |
| 特效挡住脸、手、武器或命中点 | 移开遮挡路径，收窄面积或亮度，留出主体和接触关系的识别区 |
| 特效像后期贴图 | 补充正确的前后关系、遮挡、局部反射或材质响应，并统一边缘与景深 |
| 以厚雾、全屏泛光替代效果形态 | 回到源头、轮廓、路径和作用；分别写清实际雾场与镜头光学柔化 |
| CG 主体配平面动漫符号特效 | 统一特效的体积、材质、光照和空间深度；只有用户明确要求混搭时才保留分层媒介 |

## 联动关系与加载预算

- 具体效果家族和形态选项读取同目录的 [VFX 家族参考库](../../libraries/material-effect/vfx-effect-families.md)。
- MJ 风格的主媒介、景深、柔化、晕染和散景由 [MJ 风格叶子](../../styles/cinematic/mj-atmospheric-film-look.md) 管理；不得将其散景规则重复抄入本页。
- 当光源方向或色彩本身是独立难点时，按需读取 [lighting-color control](../lighting-color/index.md)；动作、武器接触或空间关系成为重点时，按需读取 [pose-action control](../pose-action/index.md) 或 [spatial-blocking control](../spatial-blocking/index.md)。
- 特效 control 与 VFX 家族 library 各占一个按需槽位。结合 MJ 风格时为 1 control + 1 library + 1 style，保持默认加载预算。
- 完整视频时间线、连续帧状态和粒子模拟参数不属于此页。
