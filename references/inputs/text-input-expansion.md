# 纯文字输入理解与视觉规划

## 用途

把用户的文字创意先转成清楚的画面目标，再补成可执行画面结构。短请求仍按快速模式主动完成视觉规划；输入简短不等于用户只想要简短、浅层的 Prompt。不得擅自改变题材、世界观和关键人物关系。

## 何时读取

用户没有提供参考图，只通过文字描述生图、资产或参考帧需求时读取。

## 核心判断

先识别用户明确给出的锚点：

1. 当前任务是什么
2. 主体是谁或是什么
3. 画面要表达什么事件、状态或情绪
4. 场景落在哪里
5. 哪些内容用户已经锁定
6. 哪些内容允许自动补全

再做一轮内部视觉规划，不向用户展示规划过程：

1. **画面目标**：这张图要让观众先看见什么、感受到什么，或理解什么？
2. **主焦点**：第一眼必须落在哪一个对象、人物特征、动作、产品卖点或文字上？它由用户的核心目标决定，不默认由画面中最大或最靠上的元素决定。
3. **注意力层级**：确定一个主焦点、必要的次级信息和支撑气氛的元素。使用相对尺寸、位置、明暗/色彩对比、清晰度与细节密度拉开层级；不让多个元素同时争夺第一视觉。
4. **关键视觉抓手**：哪一个动作瞬间、主体特征、空间关系、材质反应或图形关系，最能让目标具体可见？
5. **维度分级**：把主体、事件、空间、构图、光线、色彩、材质、道具、风格和限制分为：
   - **锁定**：用户明确给出，准确保留；
   - **重点**：最影响辨识度、情绪、叙事或用途的 1–3 个维度，在完整描述主要画面元素的基础上进一步展开；
   - **支撑**：让重点成立所需的其他主要元素仍须写出具体形态、状态和关系，只是少写一层细节；
   - **省略**：对当前画面目标贡献很小，或会引入无依据设定的内容。

这里要区分“覆盖范围”和“展开深度”：画面中的每个主要可见元素都要被覆盖，1–3 个重点维度只决定哪些内容写得更深入，不能成为忽略其他主体、关键道具、环境锚点或文字图形的理由。人物、产品、动物、建筑、食物、自然景观、图形和文字等，均按各自的可见结构描述；主元素至少交代可辨认的形态/组成、状态或功能、画面位置/尺度、与邻近元素的关系，并补充真正影响目标的颜色、材质、表面或细节。次要元素可简洁，但不能只剩“精致、漂亮、古风、高级、柔和”等不可执行标签。

当需求使用抽象评价词时，把它转译成少数适合当前对象和风格的可见依据。例如“脸蛋漂亮”要落到脸型轮廓、眉眼形态与神态、鼻唇比例、妆面和皮肤质感中真正重要的几项；“产品高级”则落到比例、边缘、材料、工艺和表面反光等对应线索。不必把所有可列属性写满，也不要为了细致添加无关设定。Prompt 的细节量由画面复杂度、主要元素数量和各元素对目标的影响决定，不由用户原句长短或重点维度数量决定。

这套规划适用于所有从文字生成图像的任务，不只适用于海报。即使用户没有明确说“可以补充”，只要是在从零创作，未指定的构图、瞬间、姿态、光线、材质、画面节奏和风格实现等都需要根据任务自主作出协调的选择。用户明确说“适当补充 / 你来安排”时，提高对开放设计空间的主动完成度；无论授权强弱，都不能改写已锁定内容。图像编辑则只对用户允许改变的区域应用这些创意决定。

## 用户授权补全时的创意完成度

用户说“可以适当补充”“你来安排”“配上合适的文字/装饰”等，表示允许代理在未锁定的部分作出有判断的创意决定。此时不要把“最小风险”缩成只补主体、场景、光线等最低字段；要在用户给出的边界内完成一套相互支撑的画面方案，同时克制无关扩写。

内部按以下顺序完成：

1. **锁住明确要求**：主题、主体、动作、位置关系、颜色、比例、指定文案和禁止项不可被“创意优化”覆盖。
2. **找出开放的设计决定**：例如主次层级、图形结构、画面节奏、字体气质、留白如何参与构图、材质与边缘处理、少量辅助意象。
3. **选一个主设计机制**：用一个可描述的构图或图形机制把主体、背景形状和文字组织成整体，而不是只把各项元素同时放进画面。
6. **补充少量有功能的支撑**：通常只选一到两个确实帮助主题辨识、视觉节奏、信息层级或质感的细节；明确其位置、比例、形态和与主焦点的关系。
7. **校验目标风格是否可见**：除了题材或服装，至少检查版式、图形关系、字体/文字、材质/媒介、装饰节奏等是否有相互一致的画面证据。只选适合当前任务的证据，不把某一文化风格简化成固定符号清单。

不要把“画面所有元素都清楚”误当成“主次明确”。例如，当“女性审美”是核心卖点时，人物面容、神情和姿态应先被注意到；标题负责命名和吸引点击，背景色块和纱幔负责衬托人物。若任务目标是字体海报或标题本身，才让文字成为主焦点。用手机缩略图尺度检查：主焦点是否依然一眼可辨，次级与装饰是否退后。

同时辨认风格词的作用范围：

- “古风海报 / 整体古风 / 东方古典视觉”是全局风格，环境、物件、材质、字体/图形和光影都应与古风人物相协调；
- “古风女子”通常只明确锁定人物造型，不能据此断定整张图必须复原某个历史朝代；若整体方向是现代社交媒体封面，可以做有意的现代编排，但应保留能与人物呼应的字体、材料和图形语言；
- 用户未要求混搭且画面同时出现古典服饰、现代字体、摄影棚布景等不相容线索时，回到主要风格方向统一处理，或采用明确的当代东方设计语言将二者有意融合。不要把未裁决的冲突直接交给图像模型。

这里的“一致”指同一套设计意图，不要求所有元素都来自同一年代或完全相同；若选择混搭，须明确哪一层沿用古典语言、哪一层使用现代设计，以及二者通过什么共同的色彩、材质或构图机制连接。

不同图像任务使用不同的视觉规划方法，不应套用海报字段：人像可以把姿态、表情、视线、衣料和光线组织成情绪；产品图可以围绕轮廓、展示角度、材质响应和底座/背景建立产品主视觉；叙事场景可以围绕决定性瞬间、人物站位、前中后景和光源动机建立空间；插画可以围绕形状语言、线条、色彩和媒介质感形成统一表现。

海报/封面再使用专项问题：要读到什么（信息层级与准确文案）→ 眼睛如何移动（版式、留白、人物和前景关系）→ 哪些细节互相呼应（图形、道具、服装、颜色和材质）。答案要写成彼此关联的视觉关系，例如“左侧半透明纱幔沿画面边缘下垂，和右侧竖排短句形成左右呼应”，而不只是“纱幔、竖排文字”。然后把内部设计方案合并进最终 Prompt，不向快速模式用户展示拆解过程。

“合适的文字”若是开放创作授权，可以根据已给标题补写短副文案；文案必须服务主题、不添加未经支持的事实，并将字面内容、语言、层级和大致位置写清。用户给了准确文案时只保留原文。若是否新增文字会明显改变用途或信息含义，则保守地只安排用户已有文字。

例如“东方禅意极简海报”应先把方向转译成一套具体的版式、留白、色块边界、字体和材质关系；不应只靠古装人物、粉色背景和“东方美学”标签来代表风格，也不应把书法、印章、祥云、竹枝等符号全数叠加。风格成立与否以画面的整体组织和可见证据判断，不设单一审美标准。

## 画面规划与扩写顺序

```text
主体
→ 场景
→ 动作或状态
→ 空间关系
→ 画面目标、主设计机制与关键视觉抓手
→ 按优先级展开镜头与构图、光影与色彩、服装/材质/道具
→ 风格实现
→ 高风险限制项
```

这不是要求每项等量展开的字段清单。先覆盖所有主要可见元素，再把更多细节预算集中给“重点”维度；“支撑”维度可以少写，但仍须具体到能被模型画出来，不能退化成通用风格词或元素名词清单。

## 补全优先级

### 不补就会跑偏

- 主体身份
- 场景地点
- 当前任务目标
- 人物或物体数量

### 通常应主动判断的画面关键项

- **主体辨识**：最能区分主体的外形、状态、产品特征或可见身份锚点；
- **画面事件**：最有表现力且与用户意图相符的动作阶段、瞬间或静态状态；
- **观看关系**：最能呈现主体和表达目标的景别、机位、构图或视线关系；
- **视觉因果**：能解释场景、氛围或材质的光源、色彩关系、接触和环境证据。

按任务只挑真正重要的项目重点写。例如产品主图优先精写轮廓、展示角度和材质受光；情绪人像优先精写姿态、表情、视线和光线落点；叙事画面优先精写瞬间、空间关系和情绪证据。以上是判断示例，不是固定套用的额外路由。

### 影响完成度

- 材质细节
- 环境层次
- 局部道具
- 任务相关限制项

## 不主动补全

- 未被暗示的强剧情
- 会改变题材的大方向
- 用户未要求的世界观设定
- 关键人物关系
- 会把单图任务扩展成长篇叙事的内容

## 任务联动

完成输入理解和视觉规划后，必须继续读取当前任务 Playbook。任务 Playbook 可根据交付类型调整重点；输入层不直接决定资产包、编辑合同或最终输出结构。

## 输出草稿

```text
用户锚点：
画面目标：
关键视觉抓手：
重点维度（1–3 项）：
支撑维度：
省略项：
需要任务 Playbook 决定的内容：
```

此草稿只用于内部组织信息，不得在快速模式中对用户输出。
