# 服装设计图 Playbook

## 解决什么问题

把服装本身组织成可复用、可检查的设计展示板。模特只用于承载服装，人物身份与面部不是画面目标。

## 什么时候读取

- 用户要求服装设计图、服装款式板、服装三视图、服装参考板或 fashion design sheet；
- 用户需要同一套服装的正面、侧面、背面全身图，并同时展示结构细节和材质；
- 用户提供服装参考图，要求将服装设计整理为可供后续生成使用的参考板。

边界：

- 画面重点是固定角色身份、脸部、发型与服装的角色参考板 → `character-assets`；
- 单张时装人像、穿搭街拍、商业时尚主视觉 → `finished-image`；
- 在已有图片中替换服装且保留其他内容 → `image-editing`。

## 核心规则

### 画布与主视图

- 默认使用 9:16 竖版服装设计展示板，浅灰或其他干净纯色背景，版面清晰区分主展示、细节、材质和信息区域。
- 主展示区域优先呈现同一套服装的三个完整视角：正面全身、严格侧面全身、背面全身。头顶至鞋底完整入画，不裁切头部或脚部。
- 三个视角使用同一名模特、同一身高与身体比例、同一服装穿着状态、同一镜头高度与光照条件。除观察角度外，不让姿态或透视引起服装结构变化。
- 模特仅作为服装承载体。若保留人头，所有可见的正面或侧面五官必须模糊、遮蔽或无五官化处理，不得形成可识别的人脸，也不得作为人脸身份参考。背面视角不露出脸部。
- 模特以中性、稳定站姿展示服装，不让人物面部、表情或个人气质抢过服装成为焦点。

### 服装一致性与参考图

- 正、侧、背三视角必须是同一套衣物，保持上衣、下装、鞋靴、配饰和装饰件一致；前后侧视图只改变观察角度。
- 结构要能在对应视角中核对：领口、肩部、袖型、袖口、腰线、开合方式、缝线、褶皱、拼接、裙摆或裤脚，以及扣具、链条和其他配件的位置。
- 提供服装参考图时，把它绑定为服装设计主参考。忠实保留可见的廓形、结构、配色、材质线索、配件与装饰；不得自行改款、增删参考图没有的元素。原图人物的脸和身份不继承到设计板。
- 参考图未展示的部位只按已知设计作最小、连贯补全；不得把推断说成参考图中明确可见的事实。文字描述与参考图冲突时，服从用户当前明确要求。
- 只有文字描述时，先锁定用户给出的款式与细节。缺失信息用克制、与服装类型一致的方案补足，不堆叠未经要求的装饰。

### 细节特写

- 在主视图之外安排 3–5 个局部特写，自动选择最能说明该款式的结构亮点，例如领口、翻领、肩部、袖口、纽扣、缝线、腰带扣具、褶皱、拼接、裙摆、围巾织法或鞋靴结构。
- 每个特写都必须能在主视图中的同一位置找到对应结构；放大展示结构和表面特征，不创造服装上不存在的口袋、扣件、缝线、纹样或配饰。
- 用简洁边框、细引线或清楚的局部裁片关系连接细节与主服装，避免遮住三视图的关键轮廓。

### 材质展示

- 设计板包含面料与材质样片区域，展示服装实际涉及的主要布料、皮革、针织物、金属配件或鞋靴表面。每种样片都能对应到主服装上的具体部位。
- 通过可观察的织纹、表面光泽、粗糙度、柔软与挺括、厚薄、垂坠和反光表现不同材质；不要只写“高级面料”或使用彼此无法区分的通用色块。
- 参考图或文字没有支持的材质不作为既定事实。必要时可用中性样片表现用户已知的材质类别，不添加虚构的材质名称或工艺参数。

### 信息区与画面层级

- 可设置简洁信息区，按现有信息列出款式名称、服装类别、主色、材质关键词和设计关键词；文字少而准确，不与服装抢主焦点。
- 不虚构品牌、尺码、成分比例、工艺说明或不可确认的款式名称。用户没有提供且无法从设计可靠判断的信息可省略。
- 三个全身视角是第一视觉层级；细节与材质是辅助层级；信息文字只承担识别与索引作用。背景保持简洁、统一，不加入无关场景或装饰。

## Prompt 组装顺序

```text
服装设计图目标与款式主题
→ 9:16 竖版展示板与简洁背景
→ 同一模特 / 人台的正面、严格侧面、背面完整全身视图
→ 人脸去识别化，服装本身为主焦点
→ 服装固定结构、配色、鞋靴和配饰
→ 3–5 个与主视图对应的局部细节
→ 与实际服装对应的材质样片及可见质感
→ 可选且准确的简洁信息区
→ 三视角、细节、材质与文字之间的一致性限制
```

快速模式把上述内容合并为一份可直接使用的最终 Prompt，不输出设计分析或额外说明。指定目标模型或结构化输出时再按 Prompt Finalization Contract 做最小格式适配。

## 联动关系

- 文字输入：`../../inputs/text-input-expansion.md`；单张服装参考图：`../../inputs/single-image-reference.md`；多张服装参考：`../../inputs/multi-image-reference.md`。每次只读取与本轮输入匹配的一份。
- 具体面料选项确实影响结果时，按需读取 `../../libraries/material-effect/index.md` 或 `../../libraries/human/index.md`；普通请求不默认加载服装资料库。
- 复杂多图职责或互相冲突的服装参考，按需读取 `../../controls/reference-handling/index.md`。
- 不加载写实真人皮肤 control：设计板的人脸应去识别化，人物不是身份参考主体。

## 常见失败与修复

- 三视图服装改变：重新固定同一款式、剪裁、颜色、材质和配件，只允许观察角度变化；
- 模特身体或镜头比例变化：统一模特比例、站姿、相机高度、透视和脚底基线；
- 头脸可识别或抢焦点：改为无五官人台，或模糊 / 遮蔽全部可见五官；
- 全身被裁切：缩小三个视图并为头顶、手部、鞋底留出完整安全边距；
- 细节区创造新设计：逐项核对主服装，不匹配的局部特写删除或改为真实可见结构；
- 材质样片与衣物脱节：让样片对应明确部位，移除参考和描述均无依据的材质；
- 信息文字过多或错误：删掉无依据的标签，仅保留准确、短小的款式信息；
- 辅助区挤占主视图：缩减装饰与信息文字，优先确保三视角完整且服装结构可读。
