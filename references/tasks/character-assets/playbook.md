# 角色资产 Playbook

## 用途

生成可复用、可延续、可用于多场景和多镜头的角色资产，而不是只做一张漂亮成片。

## 何时读取

适用于角色设定图、三视图、多角度头像、表情板、姿态板、换装板、角色身份参考板、手部鞋履饰品道具细节、游戏角色资产和角色主视觉。

## 核心目标

先锁定角色识别，再扩展可变资产。

```text
身份锚点
→ 外貌锚点
→ 轮廓与比例
→ 发型、服装和配色
→ 固定道具
→ 可变表情、姿态和换装
→ 特殊剧情状态
→ 一致性限制
```

## 固定项

至少判断：

- 年龄感、身份和常态气质；
- 脸型、眼距、眼型、鼻唇比例、下颌和耳位；
- 发际线、分线、发型主轮廓和发色；
- 头身比、肩胯关系、体型和四肢比例；
- 主服装轮廓、长度关系和核心配色；
- 标志性饰品、伤疤、痣或固定道具。

详细固定方法读取 `../../controls/identity-consistency/character-identity-anchors.md`。

写实真人角色还必须读取 `../../controls/realism-quality/anti-ai-realism.md`，把皮肤按纹理、高光位置、质感基调、轻微不完美和光线分开写。不要只写「真实皮肤」。

## 可变项

- 表情和表情强度；
- 姿态、动作和重心；
- 换装与临时配饰；
- 场景和镜头；
- 局部妆面强度；
- 光影和色调；
- 战损、淋雨、疲惫等剧情状态。

固定项和可变项必须明确分开。

## 写实真人必须叠加皮肤真实感

角色资产默认先锁身份和版式。只要当前角色是写实真人，皮肤真实感就不是可选项，必须写入 Prompt。

满足任一条件即判定为写实真人：

- 用户明确要求写实、真人、照片质感、photoreal 或真实人像；
- 参考图是真人照片、写实摄影或写实三维人像；
- 参考图可见真实皮肤、毛孔、摄影高光，而不是平涂、线稿或赛璐璐。

不要判定为写实、也不要加载皮肤五变量的情况：

- 用户明确要求动漫、插画、像素、Q 版、厚涂、赛璐璐或其他 stylized 媒介；
- 用户明确要求瓷肌、玻璃肤、美颜磨皮或低频美容皮。

风格未写明、又没有真人参考图时，不要擅自改成写真；按用户已给的媒介或最小风险默认值执行。

写实真人角色资产读取：

```text
identity-consistency
+ anti-ai-realism
```

这已经用满默认 2 个 control 额度。不要再为了皮肤另读 `../../controls/realism-quality/fidelity-detail-enhancement.md`。那一页只用于已有成片、构图光线都不变、只补微观纹理的局部编辑。

生成角色身份参考板、三视图、头像或表情板时，应用方式：

- 右侧 Close-up、多角度头像、表情板近景：把皮肤当主体，五个变量都写到位置上；
- 正面无头全身、背面全身、三视图远景身体：只保留半哑光基调和轻微质感，不要全铺同等密度毛孔；
- 颈、手、手臂入画时，必须和脸同一套光、同一套质感，不能比脸更干净、更磨皮；
- 同一张资产板或同一套资产包里，皮肤逻辑必须一致，不能正常表情变体半哑光、微笑变体全脸水光；
- 角色身份参考板可以继续用中性背景和统一棚拍光，但棚拍不得变成美颜磨皮、全脸油膜或陶瓷蜡像。

不要把角色设计图误判成「同一张照片的保真增强」。从一张人物照片做出角色身份参考板，是新的资产生成，身份锁定后仍要按生成向皮肤规则重写各区，而不是只给原图加毛孔。

## 推荐资产包

按需要选择，不要求每次全部生成：

1. 中性背景角色识别主图；
2. 角色身份参考板；
3. 正、侧、背三视图；
4. 4–6 张多角度头像；
5. 基础表情组；
6. 常用姿态和习惯性小动作；
7. 全身中性站姿；
8. 手部、鞋履、饰品和固定道具细节；
9. 换装组；
10. 特殊状态或剧情状态；
11. 场景化角色主视觉。

## 默认角色设计图：上 1 下 3 四格

当用户要求“角色设计图”“角色参考板”“character sheet”“角色设定图”，或提供人物参考图并说“参照图中人物特征生成一张角色图 / 人物角色图”，且没有同时要求场景、动作、海报、宣传图或主视觉时，优先使用下面的结构。只有明确要求成片角色主视觉、场景化角色图或宣传用途时，才切换到普通成片或场景化路线。

这是 **上方 1 格、下方 3 格的四格版式**：上方是正脸头部特写；下方从左到右是无头正面身体、背面身体、侧面身体。头部特写默认只承载一个正常表情，正面身体格必须完整去头；背面和侧面身体格都保留完整人物头部。背面格展示后脑且不露脸；侧面格展示清晰侧脸，脸型、鼻梁、下颌、发际线和发型必须与上方正脸特写属于同一人物。需要其他表情或头部朝向时，复制整张版式，单独生成对应变体。

这类参考板把不同视觉信息分配给职责明确的面板：上方正脸特写负责主要人脸身份；下方正面身体展示服装正面且必须无头；背面身体展示服装背面与后脑；侧面身体展示人物侧面轮廓。三个身体格使用一致的全身尺度，避免裁切脚部或让不同角度变成不同角色。

### 默认画布与版式

默认采用：

```text
画布：1080 × 1920，竖屏 9:16
结构：上方 1 个横跨全宽的正脸头部特写 + 下方 3 个并排全身 Body Panel
纵向高度：上方约 36% + 下方约 64%
下方横向宽度：约 33% + 33% + 33%
背景：纯灰白色摄影棚背景，统一柔和棚拍光和轻微接地阴影
```

推荐视觉结构：

```text
┌─────────────────────────────────────────────┐
│        正脸头部特写：单一正常表情             │
│                  上方约 36%                  │
├─────────────┬─────────────┬─────────────────┤
│ 正面身体     │ 背面身体     │ 侧面身体         │
│ 无头无脸     │ 完整后脑     │ 完整侧面轮廓     │
│             │ 严格不露脸   │ 严格正侧面       │
│             │             │                 │
│             │             │                 │
└─────────────┴─────────────┴─────────────────┘
           下方约 64%，三格等宽
```

在 1080 × 1920 画布中，可近似理解为：

- 上方人脸区高约 690 px，横跨画布全宽；
- 下方身体区高约 1230 px，每格宽约 360 px；
- 下方三格保持相同宽度、人物比例和脚底基线，确保全身视图完整可辨。

尺寸可因边线和模型输出略有浮动，核心约束是竖版 9:16、上方单一正脸头部特写、下方三个等宽全身视图，且正面身体格无头。

除非用户明确要求其他版式，否则角色设计图默认使用这一上 1 下 3 布局，不改成横版三列或 2×2 网格。除非用户明确要求继承背景，否则不采纳参考图中的室内、街道、风景、道具或彩色背景。

### 默认背景与参考图职责

角色设计图默认使用干净的纯灰白摄影棚背景：浅灰到灰白的无纹理连续背景、柔和均匀的棚拍照明、极轻的地面接触阴影，不加入场景、道具、窗户、墙面纹理或明显渐变。这样可以把注意力集中在人物身份、服装结构和脸部特征上。

参考图只负责提供人物身份与外观锚点，包括脸型、五官比例、发型、体型、服装和配饰。参考图中的原有背景不继承到角色设计图，除非用户明确指定“保留参考图背景”或要求场景化呈现。

### 四个区域的固定职责

#### 上方区域：正脸 Head Close-up，约 36% 高度

**正面头部特写，作为唯一清晰的人脸身份锚点。**

- 正脸朝向镜头，头部、发型与发饰完整清楚；
- 默认只呈现一个自然、放松的正常表情；
- 画面下边界贴近下颌线，不出现颈部、肩线或服装；
- 清晰呈现脸型、五官比例、眼神、发际线、发型与发饰。

#### 左下区域：正面 Body Panel，约 1/3 宽

**正面身体 / 服装参考，必须无头、无脸。**

- 角色自然直立，展示正面身体从颈部截断位置到双脚的完整比例；
- 头部在颈部位置完整移除；
- 不出现头顶、头发、脸部、五官或残留半张脸；
- 重点展示肩宽、胸腰胯比例、四肢长度、手部、服装正面结构、衣长关系、配饰和鞋履；
- 这一格不得承担任何正面脸部身份信息。

#### 中下区域：背面 Body Panel，约 1/3 宽

**完整背面全身参考，必须包含后脑。**

- 展示同一角色从后脑、头部、颈部、背部一直到双脚的完整背面全身；
- 必须保留后脑、发型后部、发髻 / 辫子 / 马尾 / 后部轮廓等可见信息；
- 清楚展示肩背比例、服装背面结构、后部剪裁、衣摆、配饰后视关系和鞋履；
- 人物保持严格背对镜头，不转头，不露正脸或侧脸，不出现眼睛、鼻子、嘴等脸部身份信息；
- 这一格负责“完整背影 + 后脑发型 + 服装背面”，不是第二个人脸参考。

第 2 区保留头部的原因是：后脑发型、发量轮廓、发髻、辫子和头颈衔接属于角色背影资产的重要信息，同时严格背面对镜头不会引入一张低分辨率正面小脸与高清 Close-up 竞争身份。

#### 右下区域：侧面 Body Panel，约 1/3 宽

**完整人物严格正侧面全身参考。**

- 展示同一角色从头部到双脚的完整严格侧面轮廓，保留头部和可见侧脸五官；
- 头部、躯干、手臂、腿部和鞋履朝向一致，避免扭身形成 3/4 视图；
- 清楚呈现鼻部轮廓、下颌、发型侧面、服装侧面剪裁和身体厚度；侧脸的脸型、鼻梁、眼位、唇形、下颌、肤色、发际线和发型与上方正脸特写保持同一角色身份，不得换脸或擅自改变五官比例；
- 与正面及背面格保持相同头身比例、服装、配饰和全身尺度。

上方人脸区是唯一清晰的正面人脸身份来源。微笑或其他脸部朝向不是同一张默认设计图里的额外区块，而是按需复制整张四格版式生成的独立变体。

### 脸部变体规则

每个变体都必须完整保留四格：上方正脸头部特写、下方正面无头身体、背面身体、侧面身体。只允许改变用户指定的脸部变量：

- 微笑变体：只改变嘴角、唇形、牙齿可见程度和对应的眼周变化；
- 左转 45°变体：只把上方头部特写改为向左 45°，下方三个身体格和角色身份不变；
- 右转 45°变体：只把上方头部特写改为向右 45°，下方三个身体格和角色身份不变；
- 组合变化：若同时需要微笑和转向，可生成一张“指定朝向 + 指定表情”的四格变体，但不额外增加脸部格子。

所有变体保持相同画布、四格比例、背景、光线、发型、服装、身体比例和构图，只替换上方头部特写中指定的表情或朝向。

### 分区职责

```text
上方：FRONT HEAD CLOSE-UP / IDENTITY ANCHOR
正脸、单一正常表情；只含头部、发型与发饰，不露颈部和肩线。

左下：FRONT BODY / OUTFIT REFERENCE
正面身体与服装；无头、无脸。

中下：BACK BODY + REAR HEAD REFERENCE
完整背面全身；包含后脑和发型后部；严格不露脸。

右下：SIDE BODY PROFILE REFERENCE
完整侧面全身，保留侧脸；严格正侧面，五官和发型与上方正脸特写保持同一角色身份。

独立变体：SMILE / LEFT 45° / RIGHT 45° HEAD VARIANT
每张仍保留完整四格，只改变上方特写中指定的脸部变量。
```

不要让左下正面身体格重新出现头部或远景小脸；中下背面格不得转头露脸；右下侧面格保持严格侧面并展示与上方正脸一致的侧面五官。上方 Head Close-up 是主要人脸身份锚点，右下侧脸用于展示并验证同一角色的侧面轮廓。

### 单张简单参考图输入

当用户只提供一张简单人物参考图时，把该图视为人物身份主参考，而不是要求它必须已经包含完整四格信息。

- 优先锁定参考图中真实可见的脸型、五官比例、肤色、发际线、发型、年龄感与常态气质；
- 如果可见全身或大部分服装，继续锁定体型、服装轮廓、长度关系、配色和鞋履；
- 如果参考图能看到后脑或发型后部，应把这些信息优先继承到第 2 区；
- 如果参考图没有展示背面和后脑，只做与已见发型、服装和身体结构一致的最小延续，不把推断写成“参考图中原本就有”；
- 如果参考图只有头像而没有服装信息，快速模式使用简洁、中性、低识别冲突的稳定服装补全；用户已指定服装时以用户描述为准；
- 如果用户明确要求先确认或共同设计，进入交互模式后优先确认最影响角色识别的缺失信息，而不是让用户填写长表。

### 无参考图、纯文字输入

当没有参考图时，角色身份必须由文字锚点建立。至少需要形成：

```text
年龄感与性别表达
+ 脸型与关键五官比例
+ 发型 / 发色 / 发际线 / 后脑发型结构
+ 身高感、体型与身体比例
+ 主服装轮廓、长度关系与配色
+ 常态气质
```

快速模式缺少部分信息时，使用稳定、可延续、不过度设定的最小风险默认值直接补全，不中断交付。

交互模式中如果用户明确要求“可以先问我”“一起设计”“需要确认再生成”，每次只确认一个高影响变量，推荐顺序：

```text
年龄感与身份气质
→ 脸型与最关键五官
→ 发型、发色与后脑结构
→ 身高感、体型与比例
→ 主服装与配色
```

用户要求直接出结果时立即停止追问。

### 四格角色身份参考板 Prompt 组装顺序

```text
任务目标与同一角色声明
→ 参考来源与身份优先级
→ 1080×1920、9:16，上方约 36% + 下方约 64%；下方三格等宽
→ 上方：正脸、单一正常表情 Head Close-up，只含头部、发型与发饰
→ 下方三格统一纯灰白摄影棚背景与柔和棚拍光
→ 左下：正面无头无脸 Body Panel
→ 中下：完整背面全身 + 后脑 Rear Head Panel，严格不露脸
→ 右下：完整严格侧面 Body Panel
→ 跨区固定项
→ 纯灰白无纹理摄影棚背景、统一柔和棚拍光线与轻微接地阴影
→ 写实真人时：Head Close-up 皮肤五变量 + Body Panel 可见皮肤与脸同一套光
→ 关键失败限制
```

关键限制只围绕高风险问题：左下正面身体格不得出现头部、脸或头发；中下背面格不得缺失后脑，也不得转头露脸；右下侧面格必须保留侧脸并保持严格侧面，五官、脸型和发型与上方正脸特写一致；上方头部特写只出现一个正脸正常表情，且不得出现颈部、肩线或服装；独立变体不得改变身份、三个身体格、服装或构图；不得自动追加第二张脸、第二种表情或额外角色。

## 游戏角色资产交付

当角色用于游戏、动画、贴纸、UI 或建模时，先读取 `../../libraries/composition-shot/game-asset-presentation-types.md`，选择：

- 角色设定板；
- 剪影探索板；
- 表情 / 贴纸表；
- Sprite Sheet；
- 2D / 3D 转换对照；
- 载具或武器资产板；
- 宣传 Key Visual。

资产板与 Key Visual 不应混为一张：

- 资产板优先身份、比例、结构和可复用信息；
- Key Visual 优先宣传冲击、动作和世界观；
- 角色身份未稳定时，不先做强透视、强光效的主视觉；
- 网格型资产必须固定行列、单元格、基线和精确数量。

## 推荐出图顺序

先验证正常表情主图或四格角色身份参考板，再做其他三视图和头像；身份稳定后才生成微笑、左转 45°、右转 45°等独立脸部变体，再进入更多表情、姿态、换装、Sprite 和场景化主视觉。不要从强光影或强场景主视觉开始定义角色。

## 输出形态重点

### 四格角色身份参考板

默认使用 1080 × 1920 竖屏 9:16：上方约 36% 为正脸头部特写，下方约 64% 横向分为三个等宽全身格。上方格只含头部、发型与发饰，使用一个正常表情，不带颈部、肩线和服装；下方从左到右为正面无头无脸身体、完整背面身体（包含后脑但严格不露脸）、完整严格侧面身体。微笑、左转 45°、右转 45°等需求分别生成保留完整四格布局的独立变体，只改变上方特写中的指定变量。

### 三视图

锁定比例、轮廓、服装结构、正侧背对应关系和中性站姿。

### 多角度头像

锁定脸部稳定区、发际线、眼距、鼻唇关系和耳位；角度变化不能变脸。

### 表情板

明确稳定区、可变化区域和强度；优先克制或明显表情，不让每格都爆发。

### 换装板

保持人物身份、发型主锚点、体型和气质；只改变服装、材质、配色与配饰。

### 姿态板

保持骨架比例，补重心、习惯动作和角色性格；姿态变化不能改变体型。

### Sprite Sheet

固定画布尺寸、脚底基线、朝向、角色占比、动作帧顺序和每帧输入输出状态；像素媒介下按需读取 `../../styles/illustration/pixel-art-visual-language.md`。

### 细节资产

手部、鞋履、饰品、固定武器或工具必须与主图的结构和配色对应。

## 常见失败与修复

- 第 1 区仍出现头或小脸：强化“正面 Body Panel 在颈部结束，完整移除头部、头发和所有脸部五官”；
- 第 2 区被错误做成无头背身：明确“完整背面全身，从后脑到鞋底全部入镜，必须显示后脑与发型后部”；
- 第 2 区转头露出侧脸或正脸：固定严格背对镜头，只允许后脑、耳后轮廓和发型背面，不显示眼、鼻、嘴；
- 上方头部特写不是正脸或混入颈部、肩线、服装：明确正脸朝镜头，只保留头部、发型、发饰和耳部，下边界贴近下颌线；
- 下方三格被排成横版三列或 2×2：重复声明 1080 × 1920、9:16、上方约 36% 正脸头部特写、下方约 64% 三个等宽 Body Panel；
- 默认上方人脸区出现两个表情：删除额外表情格，只保留一个正常表情；
- 独立脸部变体像换了一个人：固定画布、四格比例、机位、光线、发型、服装和身体格，只允许改变上方头部特写中指定的表情或朝向；
- 右下侧面格变成 3/4 角度或侧脸换人：明确头部、躯干和四肢严格朝向同一侧，保留侧脸，并锁定与上方正脸一致的脸型、鼻梁、眼位、唇形、下颌、肤色和发型；
- 参考图背景被照搬：明确“参考图只提供人物身份与外观，不继承原背景”，改为纯灰白无纹理摄影棚背景；
- 背景过于复杂或彩色：删除场景、道具、窗户、墙面纹理和明显渐变，只保留柔和棚拍光与轻微接地阴影；
- 一微笑就换嘴：增加唇形、牙齿可见程度、嘴角和面部肌肉变化约束，降低夸张表情强度；
- 单张头像参考被擅自补成复杂服装：回退到简洁中性服装，或在交互模式确认主服装；
- 多角度变脸：补脸部稳定区，降低表情强度；
- 换装像换人：把人物身份和服装变量分开；
- 三视图比例不一致：固定头身比、肩胯和服装长度关系；
- 资产包只出脸：回补全身、手部、鞋履和道具；
- 角色依赖场景氛围：先在中性背景验证身份；
- 发型变化导致身份漂移：保留发际线、发色或其他强锚点；
- Sprite 帧基线漂移：固定单元格、脚底基线、朝向和动作阶段；
- 游戏资产被做成普通宣传图：重新选择交付类型；
- 特殊状态覆盖原身份：战损、湿发和妆面变化只能叠加，不能替换核心识别特征；
- 写实角色身份参考板只写「真实皮肤」或变成磨皮陶瓷脸：读取 `../../controls/realism-quality/anti-ai-realism.md`，头部特写拆开高光与纹理，Body Panel 可见皮肤不得比脸更光滑；
- 把写实角色设计图做成原图保真增强：回到本 Playbook，按角色身份参考板重新生成资产，而不是只给原图补毛孔；
- 动漫或像素角色被误加真人毛孔：确认媒介后删除皮肤五变量。
