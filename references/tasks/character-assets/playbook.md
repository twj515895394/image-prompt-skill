# 角色资产 Playbook

## 用途

生成可复用、可延续、可用于多场景和多镜头的角色资产，而不是只做一张漂亮成片。

## 何时读取

适用于角色设定图、三视图、多角度头像、表情板、姿态板、换装板、三分区角色身份参考板、手部鞋履饰品道具细节、游戏角色资产和角色主视觉。

## 核心目标

先锁定角色识别，再扩展可变资产。

```text
身份锚点
→ 外貌锚点
→ 轮廓与比例
→ 发型、服装和配色
→ 固定道具
→ 可变表情、姿态和换装
→ 特殊剧情状态
→ 一致性限制
```

## 固定项

至少判断：

- 年龄感、身份和常态气质；
- 脸型、眼距、眼型、鼻唇比例、下颌和耳位；
- 发际线、分线、发型主轮廓和发色；
- 头身比、肩胯关系、体型和四肢比例；
- 主服装轮廓、长度关系和核心配色；
- 标志性饰品、伤疤、痣或固定道具。

详细固定方法读取 `../../controls/identity-consistency/character-identity-anchors.md`。

写实真人角色还必须读取 `../../controls/realism-quality/anti-ai-realism.md`，把皮肤按纹理、高光位置、质感基调、轻微不完美和光线分开写。不要只写「真实皮肤」。

## 可变项

- 表情和表情强度；
- 姿态、动作和重心；
- 换装与临时配饰；
- 场景和镜头；
- 局部妆面强度；
- 光影和色调；
- 战损、淋雨、疲惫等剧情状态。

固定项和可变项必须明确分开。

## 写实真人必须叠加皮肤真实感

角色资产默认先锁身份和版式。只要当前角色是写实真人，皮肤真实感就不是可选项，必须写入 Prompt。

满足任一条件即判定为写实真人：

- 用户明确要求写实、真人、照片质感、photoreal 或真实人像；
- 参考图是真人照片、写实摄影或写实三维人像；
- 参考图可见真实皮肤、毛孔、摄影高光，而不是平涂、线稿或赛璐璐。

不要判定为写实、也不要加载皮肤五变量的情况：

- 用户明确要求动漫、插画、像素、Q 版、厚涂、赛璐璐或其他 stylized 媒介；
- 用户明确要求瓷肌、玻璃肤、美颜磨皮或低频美容皮。

风格未写明、又没有真人参考图时，不要擅自改成写真；按用户已给的媒介或最小风险默认值执行。

写实真人角色资产读取：

```text
identity-consistency
+ anti-ai-realism
```

这已经用满默认 2 个 control 额度。不要再为了皮肤另读 `../../controls/realism-quality/fidelity-detail-enhancement.md`。那一页只用于已有成片、构图光线都不变、只补微观纹理的局部编辑。

生成三分区板、三视图、头像或表情板时，应用方式：

- 右侧 Close-up、多角度头像、表情板近景：把皮肤当主体，五个变量都写到位置上；
- 正面无头全身、背面全身、三视图远景身体：只保留半哑光基调和轻微质感，不要全铺同等密度毛孔；
- 颈、手、手臂入画时，必须和脸同一套光、同一套质感，不能比脸更干净、更磨皮；
- 同一张资产板或同一套资产包里，皮肤逻辑必须一致，不能正常表情变体半哑光、微笑变体全脸水光；
- 三分区板可以继续用中性背景和统一棚拍光，但棚拍不得变成美颜磨皮、全脸油膜或陶瓷蜡像。

不要把角色设计图误判成「同一张照片的保真增强」。从一张人物照片做出三分区板，是新的资产生成，身份锁定后仍要按生成向皮肤规则重写各区，而不是只给原图加毛孔。

## 推荐资产包

按需要选择，不要求每次全部生成：

1. 中性背景角色识别主图；
2. 三分区角色身份参考板；
3. 正、侧、背三视图；
4. 4–6 张多角度头像；
5. 基础表情组；
6. 常用姿态和习惯性小动作；
7. 全身中性站姿；
8. 手部、鞋履、饰品和固定道具细节；
9. 换装组；
10. 特殊状态或剧情状态；
11. 场景化角色主视觉。

## 默认角色设计图：三个区

当用户要求“角色设计图”“角色参考板”“character sheet”“三分区设定图”，或希望用一张简单人物参考图建立稳定角色身份时，优先使用下面的结构。

这是 **3 个并列的主区**：正面身体、背面身体、人脸特写。人脸区默认只承载一个正常表情，让单张脸占满右侧大区，从而更清楚地展示脸型、眼距、鼻唇比例、发际线和皮肤细节，也避免一张设计图同时要求模型处理多个表情并造成脸部漂移。需要其他表情或脸部朝向时，复制整张三分区版式，单独生成对应变体。

这类参考板的目标不是简单展示更多角度，而是把不同视觉信息分配给职责明确的面板：正面身体与服装、背面完整轮廓与后脑发型、单一正常表情的人脸身份。避免让正面远景中的低细节小脸参与人物身份定义，同时保留背面完整头部信息用于后脑、发型和整体背影轮廓。

### 默认画布与版式

默认采用：

```text
画布：1920 × 1080，横屏 16:9
结构：2 个纵向 Body Panel + 1 个纵向 Close-up Face Panel
横向宽度：22% + 22% + 56%
```

推荐视觉结构：

```text
┌──────────┬──────────┬──────────────────────────┐
│          │          │                          │
│ FRONT    │ BACK     │   Normal Face Close-up   │
│ BODY     │ BODY     │   Identity Anchor        │
│ 22%      │ 22%      │                          │
│          │          │   单一正常表情            │
│ 无头无脸 │ 完整后脑 │                          │
│          │ + 全背身 │                          │
└──────────┴──────────┴──────────────────────────┘
                         56%
```

在 1920 × 1080 画布中，可近似理解为：

- 第 1 列约 422 px；
- 第 2 列约 422 px；
- 右侧人脸区约 1076 px，作为一个完整的大特写区，优先保证脸部特征的展示面积和辨识度。

像素值允许因排版边线和模型输出略有浮动，核心约束是保持 `22% + 22% + 56%` 的视觉权重与右侧单一大特写区。

除非用户明确要求其他版式，否则三分区角色身份参考板默认使用这一布局，不默认使用 2×2 或多表情网格。

### 三个区域的固定职责

#### 第 1 区：正面 Body Panel，22%

**正面身体 / 服装参考，必须无头、无脸。**

- 角色自然直立，展示正面身体从颈部截断位置到双脚的完整比例；
- 头部在颈部位置完整移除；
- 不出现头顶、头发、脸部、五官或残留半张脸；
- 重点展示肩宽、胸腰胯比例、四肢长度、手部、服装正面结构、衣长关系、配饰和鞋履；
- 这一格不得承担任何正面脸部身份信息。

#### 第 2 区：背面 Body Panel，22%

**完整背面全身参考，必须包含后脑。**

- 展示同一角色从后脑、头部、颈部、背部一直到双脚的完整背面全身；
- 必须保留后脑、发型后部、发髻 / 辫子 / 马尾 / 后部轮廓等可见信息；
- 清楚展示肩背比例、服装背面结构、后部剪裁、衣摆、配饰后视关系和鞋履；
- 人物保持严格背对镜头，不转头，不露正脸或侧脸，不出现眼睛、鼻子、嘴等脸部身份信息；
- 这一格负责“完整背影 + 后脑发型 + 服装背面”，不是第二个人脸参考。

第 2 区保留头部的原因是：后脑发型、发量轮廓、发髻、辫子和头颈衔接属于角色背影资产的重要信息，同时严格背面对镜头不会引入一张低分辨率正面小脸与高清 Close-up 竞争身份。

#### 第 3 区：Face Close-up

**3/4 视角正常表情大特写，Primary Identity Anchor。**

- 采用大尺寸胸像或肩部以上特写；
- 默认 3/4 视角，保持自然、放松、不过度表演的正常表情；
- 清楚呈现脸型、眉眼、眼距、鼻梁鼻翼、鼻唇比例、唇形、下颌、耳位、肤色、发际线与发型；
- 保留适量颈部、肩线与服装领口，使脸部与角色造型建立联系；
- 这一格是最主要、最清晰的人脸身份来源。

人脸区的默认职责是提供唯一、清晰、可复用的正常表情身份锚点。微笑、左转 45°、右转 45°等不是同一张默认设计图里的额外区块，而是按需复制整张三分区版式生成的独立变体。

### 脸部变体规则

每个变体都必须完整保留三个区：正面身体、背面身体、人脸特写。只允许改变用户指定的脸部变量：

- 微笑变体：只改变嘴角、唇形、牙齿可见程度和对应的眼周变化；
- 左转 45°变体：只把人脸特写改为向左 45°，身体两个区和角色身份不变；
- 右转 45°变体：只把人脸特写改为向右 45°，身体两个区和角色身份不变；
- 组合变化：若同时需要微笑和转向，可生成一张“指定朝向 + 指定表情”的三分区变体，但不额外增加脸部格子。

所有变体保持相同画布、三列比例、背景、光线、发型、服装、身体比例和构图，只替换指定的表情或脸部朝向。

### 分区职责

```text
第 1 区：FRONT BODY / OUTFIT REFERENCE
正面身体与服装；无头、无脸。

第 2 区：BACK BODY + REAR HEAD REFERENCE
完整背面全身；包含后脑和发型后部；严格不露脸。

第 3 区：NORMAL FACE IDENTITY ANCHOR
负责“这个人是谁”，默认只出现一个正常表情。

独立变体：SMILE / LEFT 45° / RIGHT 45° FACE VARIANT
每张仍保留完整三分区，只改变指定的脸部变量。
```

不要让第 1 区重新出现远景正面小脸，也不要让第 2 区转头露出脸部。正面人脸身份应集中由右侧高清 Close-up 提供。

### 单张简单参考图输入

当用户只提供一张简单人物参考图时，把该图视为人物身份主参考，而不是要求它必须已经包含完整三分区信息。

- 优先锁定参考图中真实可见的脸型、五官比例、肤色、发际线、发型、年龄感与常态气质；
- 如果可见全身或大部分服装，继续锁定体型、服装轮廓、长度关系、配色和鞋履；
- 如果参考图能看到后脑或发型后部，应把这些信息优先继承到第 2 区；
- 如果参考图没有展示背面和后脑，只做与已见发型、服装和身体结构一致的最小延续，不把推断写成“参考图中原本就有”；
- 如果参考图只有头像而没有服装信息，快速模式使用简洁、中性、低识别冲突的稳定服装补全；用户已指定服装时以用户描述为准；
- 如果用户明确要求先确认或共同设计，进入交互模式后优先确认最影响角色识别的缺失信息，而不是让用户填写长表。

### 无参考图、纯文字输入

当没有参考图时，角色身份必须由文字锚点建立。至少需要形成：

```text
年龄感与性别表达
+ 脸型与关键五官比例
+ 发型 / 发色 / 发际线 / 后脑发型结构
+ 身高感、体型与身体比例
+ 主服装轮廓、长度关系与配色
+ 常态气质
```

快速模式缺少部分信息时，使用稳定、可延续、不过度设定的最小风险默认值直接补全，不中断交付。

交互模式中如果用户明确要求“可以先问我”“一起设计”“需要确认再生成”，每次只确认一个高影响变量，推荐顺序：

```text
年龄感与身份气质
→ 脸型与最关键五官
→ 发型、发色与后脑结构
→ 身高感、体型与比例
→ 主服装与配色
```

用户要求直接出结果时立即停止追问。

### 三分区 Prompt 组装顺序

```text
任务目标与同一角色声明
→ 参考来源与身份优先级
→ 1920×1080、16:9、22% + 22% + 56% 固定布局
→ 右侧 56% 单一人脸特写区
→ 第 1 区：正面无头无脸 Body Panel
→ 第 2 区：完整背面全身 + 后脑 Rear Head Panel，严格不露脸
→ 第 3 区：正常表情 3/4 大特写 Primary Identity Anchor
→ 跨区固定项
→ 中性背景与统一棚拍光线
→ 写实真人时：Close-up 皮肤五变量 + Body Panel 可见皮肤与脸同一套光
→ 关键失败限制
```

关键限制只围绕高风险问题：第 1 区不得出现头部、脸或头发；第 2 区不得缺失后脑，也不得转头露出正脸 / 侧脸；第 3 区只出现一个正常表情；独立变体不得改变身份、身体区、服装或构图；不得自动追加第二张脸、第二种表情或额外角色。

## 游戏角色资产交付

当角色用于游戏、动画、贴纸、UI 或建模时，先读取 `../../libraries/composition-shot/game-asset-presentation-types.md`，选择：

- 角色设定板；
- 剪影探索板；
- 表情 / 贴纸表；
- Sprite Sheet；
- 2D / 3D 转换对照；
- 载具或武器资产板；
- 宣传 Key Visual。

资产板与 Key Visual 不应混为一张：

- 资产板优先身份、比例、结构和可复用信息；
- Key Visual 优先宣传冲击、动作和世界观；
- 角色身份未稳定时，不先做强透视、强光效的主视觉；
- 网格型资产必须固定行列、单元格、基线和精确数量。

## 推荐出图顺序

先验证正常表情主图或三分区角色身份参考板，再做三视图和头像；身份稳定后才生成微笑、左转 45°、右转 45°等独立脸部变体，再进入更多表情、姿态、换装、Sprite 和场景化主视觉。不要从强光影或强场景主视觉开始定义角色。

## 输出形态重点

### 三分区角色身份参考板

默认使用 1920 × 1080 横屏：左侧两个纵向 Body Panel 分别占约 22% 和 22%，右侧约 56% 为一个完整的 Face Close-up。第 1 区正面无头无脸负责正面身体与服装；第 2 区完整背面全身包含后脑，负责背影、后脑发型和服装背面；第 3 区使用一个正常表情的人脸特写负责主要身份。微笑、左转 45°、右转 45°等需求分别生成独立的三分区变体。

### 三视图

锁定比例、轮廓、服装结构、正侧背对应关系和中性站姿。

### 多角度头像

锁定脸部稳定区、发际线、眼距、鼻唇关系和耳位；角度变化不能变脸。

### 表情板

明确稳定区、可变化区域和强度；优先克制或明显表情，不让每格都爆发。

### 换装板

保持人物身份、发型主锚点、体型和气质；只改变服装、材质、配色与配饰。

### 姿态板

保持骨架比例，补重心、习惯动作和角色性格；姿态变化不能改变体型。

### Sprite Sheet

固定画布尺寸、脚底基线、朝向、角色占比、动作帧顺序和每帧输入输出状态；像素媒介下按需读取 `../../styles/illustration/pixel-art-visual-language.md`。

### 细节资产

手部、鞋履、饰品、固定武器或工具必须与主图的结构和配色对应。

## 常见失败与修复

- 第 1 区仍出现头或小脸：强化“正面 Body Panel 在颈部结束，完整移除头部、头发和所有脸部五官”；
- 第 2 区被错误做成无头背身：明确“完整背面全身，从后脑到鞋底全部入镜，必须显示后脑与发型后部”；
- 第 2 区转头露出侧脸或正脸：固定严格背对镜头，只允许后脑、耳后轮廓和发型背面，不显示眼、鼻、嘴；
- 版式退化成 2×2 或多表情网格：重复声明 1920 × 1080、两个 22% 纵向 Body Panel、右侧 56% 单一 Face Panel；
- 默认人脸区出现两个表情：删除额外表情格，只保留一个正常表情；
- 独立脸部变体像换了一个人：固定画布、三列比例、机位、焦段感、光线、发型、服装和脸部一级锚点，只允许指定的表情或朝向变化；
