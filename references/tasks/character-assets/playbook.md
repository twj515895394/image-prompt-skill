# 角色资产 Playbook

## 用途

生成可复用、可延续、可用于多场景和多镜头的角色资产，而不是只做一张漂亮成片。

## 何时读取

适用于角色设定图、三视图、多角度头像、表情板、姿态板、换装板、四区角色身份参考板、手部鞋履饰品道具细节、游戏角色资产和角色主视觉。

## 核心目标

先锁定角色识别，再扩展可变资产。

```text
身份锚点
→ 外貌锚点
→ 轮廓与比例
→ 发型、服装和配色
→ 固定道具
→ 可变表情、姿态和换装
→ 特殊剧情状态
→ 一致性限制
```

## 固定项

至少判断：

- 年龄感、身份和常态气质；
- 脸型、眼距、眼型、鼻唇比例、下颌和耳位；
- 发际线、分线、发型主轮廓和发色；
- 头身比、肩胯关系、体型和四肢比例；
- 主服装轮廓、长度关系和核心配色；
- 标志性饰品、伤疤、痣或固定道具。

详细固定方法读取 `../../controls/identity-consistency/character-identity-anchors.md`。

## 可变项

- 表情和表情强度；
- 姿态、动作和重心；
- 换装与临时配饰；
- 场景和镜头；
- 局部妆面强度；
- 光影和色调；
- 战损、淋雨、疲惫等剧情状态。

固定项和可变项必须明确分开。

## 推荐资产包

按需要选择，不要求每次全部生成：

1. 中性背景角色识别主图；
2. 四区角色身份参考板；
3. 正、侧、背三视图；
4. 4–6 张多角度头像；
5. 基础表情组；
6. 常用姿态和习惯性小动作；
7. 全身中性站姿；
8. 手部、鞋履、饰品和固定道具细节；
9. 换装组；
10. 特殊状态或剧情状态；
11. 场景化角色主视觉。

## 四区角色身份参考板

当用户要求“角色设计图”“角色参考板”“四区设定图”，或希望用一张简单人物参考图建立稳定角色身份时，优先使用下面的四区结构。目标不是展示更多角度，而是把身体 / 服装参考与脸部身份 / 表情参考分离，避免全身远景中的低细节小脸参与身份定义。

### 四区固定布局

同一张横向角色板从左到右保持四个清晰分区：

1. **正面全身无头图**：角色自然直立，完整展示从脚到颈部的正面身体比例、服装正面结构、手部和鞋履；头部在颈部位置干净移除，不出现脸、头发或残留五官。
2. **背面全身无头图**：同一角色自然直立，完整展示从脚到颈部的背面身体比例、服装背面结构、后部剪裁和鞋履；同样不出现脸部。
3. **3/4 视角中性脸部大特写**：作为主要人脸身份锚点，保持自然闭嘴中性表情，清楚呈现脸型、眉眼、眼距、鼻唇比例、下颌、耳位、发际线、发型和肤色。
4. **3/4 视角微笑脸部大特写**：与第 3 区保持同一人物、相近机位、焦段感、光线、发型和造型，只改变表情；使用自然微笑，可轻微露齿，用于稳定嘴型、牙齿、脸颊和眼周在微笑状态下的身份表现。

### 分区职责

```text
第 1–2 区：BODY / OUTFIT REFERENCE
只负责身体比例、轮廓、服装和鞋履，不提供脸部身份。

第 3 区：NEUTRAL IDENTITY ANCHOR
负责“这个人是谁”。

第 4 区：SMILE EXPRESSION ANCHOR
负责“这个人笑起来是什么样”。
```

不要为了“信息更多”让第 1、2 区重新出现远景小脸。角色身份应集中由高清脸部特写提供。

### 单张简单参考图输入

当用户只提供一张简单人物参考图时，把该图视为人物身份主参考，而不是要求它必须已经包含完整四区信息。

- 优先锁定参考图中真实可见的脸型、五官比例、肤色、发际线、发型、年龄感与常态气质；
- 如果可见全身或大部分服装，继续锁定体型、服装轮廓、长度关系、配色和鞋履；
- 对参考图没有展示的背面服装、遮挡区域和细节，只做与已见结构一致的最小延续，不把推断写成“参考图中原本就有”；
- 如果参考图只有头像而没有服装信息，快速模式使用简洁、中性、低识别冲突的稳定服装补全；用户已指定服装时以用户描述为准；
- 如果用户明确要求先确认或共同设计，进入交互模式后优先确认最影响角色识别的缺失信息，而不是让用户填写长表。

### 无参考图、纯文字输入

当没有参考图时，角色身份必须由文字锚点建立。至少需要形成：

```text
年龄感与性别表达
+ 脸型与关键五官比例
+ 发型 / 发色 / 发际线
+ 身高感、体型与身体比例
+ 主服装轮廓、长度关系与配色
+ 常态气质
```

快速模式缺少部分信息时，使用稳定、可延续、不过度设定的最小风险默认值直接补全，不中断交付。

交互模式中如果用户明确要求“可以先问我”“一起设计”“需要确认再生成”，每次只确认一个高影响变量，推荐顺序：

```text
年龄感与身份气质
→ 脸型与最关键五官
→ 发型与发色
→ 身高感、体型与比例
→ 主服装与配色
```

用户要求直接出结果时立即停止追问。

### 四区 Prompt 组装顺序

```text
任务目标与同一角色声明
→ 参考来源与身份优先级
→ 四区横向布局
→ 第 1 区正面无头全身
→ 第 2 区背面无头全身
→ 第 3 区中性 3/4 脸部大特写
→ 第 4 区微笑 3/4 脸部大特写
→ 跨区固定项
→ 中性背景与统一棚拍光线
→ 关键失败限制
```

关键限制只围绕高风险问题：前两区不得残留脸或头发；后两区不得变成不同人物；微笑不得导致嘴型、牙齿或脸部比例漂移；四区不得出现额外角色或不一致服装。

## 游戏角色资产交付

当角色用于游戏、动画、贴纸、UI 或建模时，先读取 `../../libraries/composition-shot/game-asset-presentation-types.md`，选择：

- 角色设定板；
- 剪影探索板；
- 表情 / 贴纸表；
- Sprite Sheet；
- 2D / 3D 转换对照；
- 载具或武器资产板；
- 宣传 Key Visual。

资产板与 Key Visual 不应混为一张：

- 资产板优先身份、比例、结构和可复用信息；
- Key Visual 优先宣传冲击、动作和世界观；
- 角色身份未稳定时，不先做强透视、强光效的主视觉；
- 网格型资产必须固定行列、单元格、基线和精确数量。

## 推荐出图顺序

先验证中性主图或四区角色身份参考板，再做三视图和头像；身份稳定后才进入表情、姿态、换装、Sprite 和场景化主视觉。不要从强光影或强场景主视觉开始定义角色。

## 输出形态重点

### 四区角色身份参考板

锁定“身体 / 服装”和“脸部 / 表情”的职责分离。前两区无头全身负责身体与服装，后两区大脸特写分别负责中性身份和微笑表情锚点。

### 三视图

锁定比例、轮廓、服装结构、正侧背对应关系和中性站姿。

### 多角度头像

锁定脸部稳定区、发际线、眼距、鼻唇关系和耳位；角度变化不能变脸。

### 表情板

明确稳定区、可变化区域和强度；优先克制或明显表情，不让每格都爆发。

### 换装板

保持人物身份、发型主锚点、体型和气质；只改变服装、材质、配色与配饰。

### 姿态板

保持骨架比例，补重心、习惯动作和角色性格；姿态变化不能改变体型。

### Sprite Sheet

固定画布尺寸、脚底基线、朝向、角色占比、动作帧顺序和每帧输入输出状态；像素媒介下按需读取 `../../styles/illustration/pixel-art-visual-language.md`。

### 细节资产

手部、鞋履、饰品、固定武器或工具必须与主图的结构和配色对应。

## 常见失败与修复

- 四区前两格仍出现小脸：明确在颈部结束并完全移除头部、脸部与头发；
- 中性脸和微笑脸像两个人：固定机位、焦段感、光线、发型和脸部一级锚点，只允许表情变化；
- 一微笑就换嘴：增加唇形、牙齿可见程度、嘴角和面部肌肉变化约束，降低夸张表情强度；
- 单张头像参考被擅自补成复杂服装：回退到简洁中性服装，或在交互模式确认主服装；
- 多角度变脸：补脸部稳定区，降低表情强度；
- 换装像换人：把人物身份和服装变量分开；
- 三视图比例不一致：固定头身比、肩胯和服装长度关系；
- 资产包只出脸：回补全身、手部、鞋履和道具；
- 角色依赖场景氛围：先在中性背景验证身份；
- 发型变化导致身份漂移：保留发际线、发色或其他强锚点；
- Sprite 帧基线漂移：固定单元格、脚底基线、朝向和动作阶段；
- 游戏资产被做成普通宣传图：重新选择交付类型；
- 特殊状态覆盖原身份：战损、湿发和妆面变化只能叠加，不能替换核心识别特征。
