# 成片生图 Playbook

## 用途

生成一张高完成度结果图，而不是资产清单、风格词列表或灵感摘要。

## 何时读取

适用于：

- 人物写真或叙事瞬间
- 产品图、电商图和产品主视觉
- 海报、封面和宣传画面
- 电影感画面与概念图
- 动漫、漫画、插画和 3D 成片

## 生成前内部视觉规划

快速模式下，每种成片任务都必须先形成足以指导最终图像的视觉方案，再写 Prompt。规划方法根据人像、产品、叙事场景、插画、海报等任务灵活变化；不能只照抄需求里的名词，也不能套用同一张维度清单。简短请求不触发追问，也不代表只给短关键词。

内部先回答：

1. 这张图要传达什么？用户最看重的结果是什么？
2. 观众第一眼应该看什么？明确一个主焦点，不让次要元素与它争抢。
3. 哪些次级信息能补充主焦点？哪些仅负责空间、情绪或材质支撑？
4. 用主体占比、位置、明暗/色彩对比、景深和细节密度怎样实现上述顺序？
5. 哪 1–3 个维度最影响这张图的辨识度、情绪、叙事或用途？
6. 哪些细节没有明显贡献，应该省略？

主焦点必须在最终 Prompt 里得到最高注意力权重；次级内容负责解释、命名或增强它，背景与装饰退到支撑层。通过画面占比、位置、对比和细节量体现层级，不能只写“突出主体”。重点维度要精确描述到可见、可定位、可执行；支撑维度简洁写清即可。不要平均展开全部维度，也不要用额外世界观、强剧情、堆叠道具或空泛质量词填充空白。Prompt 深度取决于画面目标和任务复杂度，而不是用户输入长度。

从零生成的图像任务默认要求对未指定但影响成片的内容作出合理、具体的设计选择。用户明确允许补充时，主动完成开放部分，不把“最小风险”当作“最低完成度”。选择适合当前任务的主视觉机制，让重点要素彼此支撑；人物、产品、叙事场景和插画各用适合自身的组织逻辑。图像编辑只在用户允许变化的范围内这样做。

海报与封面不能只完成“主角 + 背景色 + 标题”清单，还要判断第一焦点应由主视觉还是标题承担，再安排其他文字、色块和装饰如何对齐、重叠、平衡、形成阅读顺序，以及材质和边缘处理如何服务目标风格。

海报类任务先做一次内部艺术指导拆解，再写 Prompt：

1. **信息系统**：选定第一视觉落点，明确标题、副文案和辅助文字的内容、阅读顺序、相对字号与安全区；用户授权写“合适文案”时，先拟好短而准确的具体字句。
2. **版式与空间系统**：选一个适合文字量和比例的版式，安排主体、色块、留白、前景和承载文字的平整区域，描述对齐、穿插、遮挡边界及视线动线。
3. **视觉呼应系统**：挑一个主视觉机制和少量辅助母题，让背景形状、道具、服装细节、色彩或材质之间形成可见呼应；说明元素的位置和作用，不把名词罗列当成设计。

这些是内部决策层，不要求最终 Prompt 输出分析报告。它们合并后应形成一段能直接执行的整体画面描述。参考图可用于推断其构图和设计关系，但只能重构可观察的视觉逻辑，不能声称知道原作者实际使用的 Prompt。

风格检查要看可见的实现证据，而不是只检查风格词和题材符号是否出现。若指定风格主要靠服装或单一颜色提示，应继续判断版式、图形语言、字体、表面质感或装饰节奏中是否需要一至两项协调补足；不必全部加入，也不要把文化风格套成固定符号模板。明确要求的色彩、主体位置、比例与文字优先保留。

图片内的“合适文案”只在用户明确开放文字创作时补写。副文案短、主题相关、无虚构事实，并在 Prompt 中固定准确字面内容与层级；否则只编排用户已提供的文字。

## 最少需要锁定

- 主体是谁或是什么
- 画面要表达什么事件、状态或情绪
- 场景在哪里
- 观众以什么距离和角度观看

缺少的信息优先依据用户意图、任务类型和最小风险默认值推断。除非用户明确要求讨论、脑暴、逐步设计或先提问，不因信息缺失、歧义或画面复杂而转入交互模式；对仍不确定的方向采用保守、可视化且不改变题材的默认方案。

## Prompt 组装顺序

```text
主体身份与辨识点
→ 场景与空间关系
→ 动作、状态或事件瞬间
→ 画面目标与关键视觉抓手
→ 重点维度的镜头/构图、光影/色彩或材质细化
→ 必要的支撑细节
→ 风格实现
→ 任务相关限制
```

不要先写风格，再回头补主体。
以上顺序不代表各部分篇幅相同。先确定对结果最有影响的 1–3 个维度，细写它们；其余只写到保持画面成立所需的程度。

## 写实成片的路由边界

当用户明确要求真实照片感、去 AI 感、自然生活、可信材质，或反感塑料皮、假景深和过度精修时，读取 `../../controls/realism-quality/index.md`，以 `../../controls/realism-quality/anti-ai-realism.md` 为主，必要时最多再叠加一个相邻 control。不要为达到默认预算而同时加载所有写实相关叶子。

商业人像、产品广告和写实 CGI 可以保持洁净、对称或理想化；只有用户目标是自然照片或去合成感时，才加入生活化构图和受控不完美。

## 输出形态判断

### 人物成片

重点关注：身份、外貌锚点、姿态、表情、服装、镜头和光影。

近景或中近景需要真实皮肤时，读取 `../../controls/realism-quality/anti-ai-realism.md`，把纹理、高光位置和半哑光基调分开写；不要只加「真实皮肤」。已有成片只补微观细节时，改走局部编辑。

### 产品成片

重点关注：产品形态、展示角度、材质、结构、背景、光线、比例和文字准确性。

### 海报或封面

重点关注：视觉层级、主体位置、留白、标题区、色彩冲突和信息可读性。若用户让你补全设计，额外检查版式选择、图文阅读顺序、前中后景、元素之间的呼应和文字准确性；不止列出画面里“有什么”。

### 电影或叙事画面

重点关注：事件发生中的瞬间、空间关系、角色视线、光源动机和情绪落点。

### 概念图

重点关注：设计目标、轮廓、功能、材质、尺度参照和世界观一致性。

## 输出骨架

```text
画面概述：
主要约束：
最终 Prompt：
备选 Prompt：
已自动补全项或方向决策摘要：
```

备选 Prompt 不是必须；只有确实存在另一条有价值方向时再提供。

## 常见失败与修复

- 主体不清楚：减少风格词，增加身份、轮廓和辨识锚点
- 场景漂亮但无叙事作用：明确主体与环境的关系
- 镜头与光影冲突：让光源方向服务当前机位和视觉重点
- 细节很多但主次不明：收窄背景信息，重新建立第一视觉落点
- 画面像模板图：补具体事件、动作阶段和环境证据
- 限制项过多：只压制当前最危险的失败模式
