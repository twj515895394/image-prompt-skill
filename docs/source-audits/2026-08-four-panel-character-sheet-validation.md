# 2026-08 四区角色身份参考板验证

## 验证目标

验证 `character-assets` 对四区角色身份参考板的路由、版式、输入兼容和高风险失败限制，同时确保不破坏现有快速 / 交互模式和默认加载预算。

## 固定预期

```text
画布：1920 × 1080，16:9
布局：22% + 22% + 56%
右侧：上下 50% / 50%

第 1 列：正面全身，唯一去头区域；无头、无脸、无头发
第 2 列：完整背面全身；包含后脑与发型后部；严格不露脸
右上：3/4 中性 Close-up
右下：同角度自然微笑 Close-up
```

## 正向回归

### Case 1：单张简单人物参考图生成四区角色设计图 Prompt

用户请求：

```text
参考这张人物照片，给我生成一份四区角色设计图的图片编辑 Prompt。
```

预期：

- 输入：`single-image-reference`
- 任务：`character-assets`
- 按需读取身份一致性 control
- 输出一份完整四区 Prompt，不拆成四个互相独立的角色
- 第一列必须明确去掉完整头部
- 第二列必须明确保留完整后脑和发型后部
- 右侧两格保持同一人物，只改变中性 / 微笑表情
- 默认采用 1920×1080、22% + 22% + 56%、右侧 50/50

结果：规则覆盖。

### Case 2：无参考图、只有人物文字描述

用户请求：

```text
设计一个 35 岁中国男性侦探的四区角色参考板，短发，瘦高，灰色风衣。
```

预期：

- 输入：`text-input-expansion`
- 任务：`character-assets`
- 快速模式不因缺少精确五官而追问
- 自动补全稳定、不过度设定的脸型和五官锚点
- 第一列无头无脸；第二列保留短发后脑
- 中性 / 微笑 Close-up 共享同一身份锚点

结果：规则覆盖。

### Case 3：用户明确要求先确认角色外貌

用户请求：

```text
我没有参考图，想做一个古代女性角色的四区设定图，先问我需要确认的外貌信息。
```

预期：

- 进入交互模式
- 每次只问一个最高影响变量
- 推荐顺序：年龄感与气质 → 脸型 / 关键五官 → 发型、发色与后脑结构 → 身材比例 → 主服装与配色
- 用户要求直接出结果时立即停止追问

结果：规则覆盖。

## 关键错误回归

### Case 4：禁止把两列 Body Panel 都做成无头

错误输出：

```text
第一列正面无头
第二列背面无头
```

必须判定为失败。

修复要求：

```text
只有第一列去头。
第二列必须从后脑到鞋底完整入镜，包含后脑、头部和发型后部，但严格背对镜头、不露脸。
```

### Case 5：禁止第一列出现正面小脸

第一列如果出现完整头部、半张脸、头发残留或可识别五官，必须判定为失败。

### Case 6：禁止第二列转头露脸

第二列允许并要求完整后脑，但如果人物回头、露侧脸、露眼鼻嘴或形成第二张人脸身份参考，必须判定为失败。

### Case 7：禁止布局退化成 2×2

在用户未指定其他版式时，四区角色身份参考板若输出 2×2 等分网格，必须判定为不符合默认布局。

正确默认：

```text
两个全高纵向 Body Panel：22% + 22%
右侧大 Face 区：56%
Face 区上下 50 / 50
```

### Case 8：微笑导致换脸

右下微笑 Close-up 如果改变脸型、眼距、鼻唇比例、发际线、主要发型或人物年龄感，应判定为身份一致性失败。

## 相邻任务反向回归

以下请求不应默认套用四区角色板：

- “给我一张电影感人物写真” → `finished-image`
- “给角色做正侧背三视图” → `character-assets` 的普通三视图路线
- “做 8 种表情表情板” → `character-assets` 的表情板路线
- “只把人物衣服换成西装” → 按整体图生图或局部编辑目标判断，不因有人物自动使用四区板

## 加载预算

典型四区请求保持：

```text
1 input
1 character-assets task
0–2 controls（通常 identity-consistency，必要时 reference-handling）
0–2 libraries
0–1 style
0–1 diagnostic
```

无需创建单独的四区 layout control，避免同一规则出现第二份正文真源。

## 结论

四区角色身份参考板应把以下约束视为不可混淆的结构规则：

```text
ONLY PANEL 1 IS HEADLESS.
PANEL 2 MUST INCLUDE THE REAR HEAD BUT MUST NOT SHOW THE FACE.
```

中文等价规则：

```text
只有第一列去头；第二列必须有后脑，但绝对不能露脸。
```
